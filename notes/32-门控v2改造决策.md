# 门控 v2 改造决策（2026-10-19）

## 结论

当前 2k pilot 只能证明训练管线正常，不能证明门控有效。

最终实测：

```text
loss: 1.1584 -> 0.1335
gate suppression: 0.2014%
target rho (2000/10000 * 0.3): 6.0%
```

因此：

> **停止扩到 20k。保留 2k checkpoint 作为 pipeline baseline，不把它当方法结果。**

## 评论里哪些判断是对的

### 完全同意

1. 当前实现不是忠实的 DomainDrop/DgCD。
2. 当前是全局、连续、弱尺度软门控，不是 per-sample 强 dropout。
3. 0.999 初始化导致 sigmoid 饱和，优化尺度不匹配。
4. 12 层同时轻微抑制，不如单层强扰动。
5. 没有 mask 重归一化。
6. 没有 gated/ungated 一致性约束。
7. DgCD 在 batch=32、50 个 style 下按域分组不可靠。
8. `dgcd_rho=1e-3` 与官方 `0.05` 相差 50 倍。
9. 推理时门控一直生效，和 dropout 语义不同。
10. 没有证明 ViT hidden channel 具有 CNN channel 那样的域选择性。

### 需要保留的判断

- DINOv2 预训练 + 全量微调是正确的。
- 动作重要性 `v_action` 是 DomainDrop/DgCD 没有的，仍然是我们的独立贡献。
- 渐进预算 `rho(t)` 是合理思想，不能因为当前实现弱就丢掉。
- 当前 soft gate 可以保留为消融，不作为主方法。

## v2 主方法

> **Action-aware per-sample hard channel dropout for Diffusion Policy.**

建议的正向流程：

```text
DINOv2 特征
  -> 取某一层（每步随机选 1 层，概率 0.8）
  -> 按域标签训练域分类器 / 域分数
  -> u = 域敏感通道分数
  -> v = 动作重要性（|f · ∂L_action/∂f|）
  -> s = normalize(u) - λ * normalize(v)
  -> 每样本选 top 33% 通道
  -> hard mask
  -> mask * C / sum(mask) 重归一化
  -> 只在该层施加
```

反向：

- hard mask 前向为 0/1；
- 用 straight-through / hard-concrete 反向；
- 第一版优先实现 **top-k straight-through**，比纯 Bernoulli 稳定；
- hard-concrete 作为第二版参数化。

### 为什么先选 DomainDrop-style 域分类器

DgCD 在 batch=32 下按 50 个 style 分组不可靠。主方法先采用：

```text
pooled feature -> domain classifier (50-way)
channel score u = W[y_d] * GAP(F)
```

优点：

- 每个样本都贡献域分类梯度；
- 不要求每个 style 在 batch 中有 ≥2 个样本；
- 天然 per-sample；
- 与 DomainDrop 官方机制一致。

DgCD 保留为 baseline：

```text
DgCD score + domain-balanced sampler (16 styles × 2 samples)
```

### 动作保护

不要再用全局 `L_gate` 的弱项来保护；直接把动作重要性放进 mask 分数：

```text
s = zscore(u) - lambda_action * zscore(v_action)
```

`v_action` 高的通道分数降低，更不容易被丢弃。

### 层选择

```text
每个训练 step 随机选 1 层
drop_ratio = 0.33
layer_wise_prob = 0.8
```

其它层恒等。这样接近 DomainDrop/PLACE 的强扰动，不是 12 层同时微调。

### 一致性

至少做特征级，最好做动作级：

```text
L_cons = MSE(action_gated, action_ungated.detach())
```

若双前向太贵，先做 gated/ungated pooled feature consistency，
再升级为动作预测一致性。

### 推理行为

默认：

```text
训练时 dropout，推理时关闭
```

同时报告：

```text
推理关闭门控
推理保留期望门控
推理保留 hard mask
```

三者作为消融，不混为一谈。

## 必须实现的对照

| 方法 | 说明 |
|---|---|
| Vanilla DP | 无门控 |
| Random channel dropout | 随机丢 33% |
| DomainDrop-style | 域分类器 + 单层硬 dropout + 一致性 |
| DgCD-style | 域平衡采样 + WRS + hard mask + 重归一化 |
| RSC-style | 梯度分位数 mask |
| Current soft gate | 当前 12 层全局连续门控 |
| Ours | 动作重要性保护的 per-sample hard mask |

## 实验顺序

1. **500 步机制探针**
   - 固定 DINOv2/DiT 或只训门控；
   - 只比较 mask 的 dropout 比例、层选择、u/v 分数；
   - 先看 suppression 和 mask IoU，不看成功率。
2. **2k 小 pilot**
   - 主方法 vs Random vs DomainDrop vs DgCD vs current soft；
   - 看训练稳定性和动作 MSE。
3. **只在机制验证通过后**再跑 20k 和闭环评测。
