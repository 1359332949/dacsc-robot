# 数据集调研：RoboCasa365 的定位与可用性（2026-10-16）

## 一、RoboCasa365 是最新的数据集吗？

**是 2026 年最主流的「仿真」基准之一，但远不是「默认」。**

| 事实 | 值 |
|---|---|
| 发布 | **2026-02-18**（v1.0），2026-05-12 v1.0.1，2026-10-14 仍在更新 |
| 论文 | [arXiv 2603.04356](https://arxiv.org/abs/2603.04356)，**ICLR 2026**，UT Austin |
| 规模 | 365 任务（65 atomic + 300 composite）、**2500 厨房场景**、**2200+ 小时**示范数据 |
| 组成 | pretraining ~2000h = 人类遥操作 **482h**（300 任务 × 100 demo）+ MimicGen 合成 **1615h**（60 atomic 任务 × ~10k demo）；target **193h** |
| 特色 | scene = layout × style（50×50 预训练，10×10 目标且不重叠）；支持多任务学习 / 基础模型训练 / 终身学习三种范式 |

**同期还有更新的东西**（不是只有 RoboCasa365 是新的）：
- 真机大数据：**Xiaomi-Robotics-1**（2026-07，10 万小时真实轨迹）
- 仿真基准：**RoboTwin 2.0**（ICML 2026）、**RoboDojo**（2026-10，含 Generalization 维度）
- 评测标准：**XPolicyLab**（2026-10，69 个策略统一评测）

### 历史分期（谁在什么时候是默认）

| 时期 | 默认基准 | 说明 |
|---|---|---|
| 2019–2021 | **Meta-World / RLBench** | RL 时代，状态输入为主 |

**结论**：我们选 RoboCasa365 不是因为它是"唯一最新"，而是因为它是**唯一同时具备「2500 场景 × layout/style 显式标注」的仿真基准**——这正好是我们研究外观域泛化需要的。LIBERO 虽然使用量是它的 28 倍，但 LIBERO 的场景/外观多样性远不如 RoboCasa365。

## 三、我们能够使用吗？——能，但有网络前提

### 授权（已核实，官方 README）

```
Code:                MIT License
Assets and Datasets: CC BY 4.0
```

**完全可用**：可修改、可商用、可再分发，只需署名。这一点比对比方法里几个仓库好得多（RoboSaGA 无 license、RoboVIP 无 license）。

### 获取路径（三条，各自独立）

| 内容 | 来源 | 方式 | 本机可达性 |
|---|---|---|---|
| 代码 | GitHub | `git clone` / tarball | ✅ 可达（已拉取） |
| **数据集** | **Box**（utexas.box.com，410 个 tar 包） | `python -m robocasa.scripts.download_datasets --all` | ❌ **不可达** |
| **场景资产** | **Box**（~10GB，官方警告） | `python -m robocasa.scripts.download_kitchen_assets` | ❌ **不可达** |
| 官方 checkpoint（DP/π0/π0.5/GR00T） | **HuggingFace** `robocasa/robocasa365_checkpoints` | `hf download` | ❌ **不可达** |

### 本机网络实测（2026-10-16）

| 目标 | 结果 |
|---|---|
| github.com（git 协议） | ❌ 挂起 |
| codeload / api / raw.githubusercontent | ✅ 可用（27–55 KB/s） |
| **utexas.box.com**（数据集与资产） | ❌ `/s/<id>` 与 `/shared/static/<id>.tar` 均返回 301/404，无内容 |
| **huggingface.co** | ❌ HTTP 000 |
| export.arxiv.org | ✅ 可用（有速率限制，429） |

**结论：数据下载必须换网络环境**（在能访问 Box 与 HF 的机器上执行）。我已经把下载命令与校验方式准备好，但**本机无法验证**。

### 数据包结构（从 box_links_ds.json 实测）

```
410 个 Box 包 = pretrain 360 个（其中 MimicGen 60 个） + target 50 个
key 形如: pretrain/atomic/AdjustToasterOvenTemperature/20250820/lerobot.tar
```

### 存储需求（粗估，官方未给总体积）

官方只提示**资产约 10GB**。数据侧按 horizon 上限粗估：

```
300 任务 × 100 demo = 30,000 条轨迹
horizon 均值 2112 步（registry 317 任务）→ 上限约 63M 帧（单相机）
× 3 相机 → 数 TB 级（实际 demo 短于 horizon 上限，真实值会小）
```

**建议预留 ≥1 TB，并在下载前用 `--dryrun` 先看清单。** 只想跑外观域实验的话，不需要全量：挑 1 个 task_set + 少量任务即可起步（几百 GB 以内）。

### 4 个必须先知道的坑

1. **RoboCasa 数据体积大**：`--all` 会拉 pretrain+target 全部；建议按 `--tasks` 精选。
2. **v1.0.1 的 horizon 改动**：2026-05-12 起所有任务 horizon ×1.5，**旧版 checkpoint 与新版评测不匹配**，务必用最新版跑 eval。
3. **本机不可达**：Box / HF 都要换网络；GitHub 只有 codeload/api/raw 通。
4. **许可混淆风险**：仓库 license 字段是 `NOASSERTION`，但 README 明确 代码 MIT + 资产/数据 CC BY 4.0 —— 引用时写后者。
