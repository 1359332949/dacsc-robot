# 恒源云（GPUShare）部署清单

> 适用场景：从 AutoDL 切到恒源云。核心差异是**数据盘是 `/hy-tmp`**，
> 不是 `/root/autodl-tmp`。项目脚本已自动识别两者。

## 1. 选机器

- 计费：选 **payg / 按量付费**，不要先买月租
- GPU：优先 **RTX 5090 32GB**
- 备选：RTX 4090D 24GB、A100 40GB、A100 80GB
- CPU：16 核以上
- 内存：64GB 以上
- 数据盘：50GB 以上（atomic 5.3GB + 环境 + checkpoint）
- 地区：西南/北京均可，选延迟低、有卡的

## 2. 镜像

### 如果选 RTX 5090

RTX 5090 是 Blackwell `sm_120`，必须选：

```text
PyTorch >= 2.7
CUDA >= 12.8
Python 3.11
```

不要选 CUDA 12.0/12.1/12.4 的旧镜像。

### 如果选 4090-48G（当前截图）

显卡驱动最高 CUDA 12.4，选：

```text
PyTorch 2.5/2.6
CUDA 12.4
Python 3.11
```

项目 `setup_server.sh` 已把 diffusers/transformers 固定到兼容版本：
`diffusers==0.31.0`、`transformers==4.46.3`、`numpy<2`。

### 4090-48G 是什么

官方 RTX 4090 只有 24GB。48GB 版本几乎一定是**改显存卡**，
不是 NVIDIA 官方规格。它通常可以跑，但要注意：

- 先跑 10 分钟 BF16 matmul/训练压力测试
- 观察是否掉卡、重启、驱动报错
- 不适合长期满载，但按小时租来做实验可以接受
- 不要把它当成有 ECC 的数据中心卡

开机后验证：

```bash
python - <<'PY'
import torch
print(torch.__version__, torch.version.cuda)
print(torch.cuda.is_available(), torch.cuda.get_device_name(0))
print(torch.cuda.get_device_capability(0))
x = torch.randn(4096, 4096, device="cuda", dtype=torch.bfloat16)
print((x @ x).abs().mean().item())
PY
```

5090 期望 `capability == (12, 0)`；4090 期望 `(8, 9)`。BF16 matmul 都必须正常。

## 3. 目录与 20GB 系统盘

```text
/root/dacsc-robot/                 代码
/hy-tmp/datasets/robocasa365/      数据集
/hy-tmp/runs/dacsc-robot/          checkpoint / 训练输出
/hy-tmp/cache/                     pip / torch / HF 缓存
```

当前实例系统盘只有 **20GB**，数据盘 **50GB 且不可扩容**：

- atomic 预训练数据 5.3GB：够
- target atomic 9.17GB：也够（总计约 15GB）
- composite 数据 100GB 级：**不够，后续必须换更大数据盘**
- checkpoint 每个约 0.7GB，建议 topk=2，避免存 20 个把盘塞满

`setup_server.sh` 会自动把 pip/TMP/HF/torch 缓存重定向到 `/hy-tmp`。

如果登录用户不是 root，把 `/root/dacsc-robot` 换成你的 HOME 下目录，
并设置：

```bash
export DACSC_ROOT=/home/你的用户名/dacsc-robot
```


## 7. 首次 GPU 探针

不要直接开 20k 步。先小 batch 跑 500–1000 步：

```bash
python3 scripts/train_smoke_test.py
```

然后在真实数据配置上用 batch 8/16/24/32 逐个试，记录
`torch.cuda.max_memory_allocated()`，找到峰值低于显存 85% 的最大 batch。

## 8. 预算

按 5090 约 3 元/小时：

- 20k 步 pilot：约 15–30 元
- 50k 步：约 30–75 元
- 250k 步完整训练：约 150–300 元

闭环评测另算。先短租 pilot，确认趋势后再扩规模。

## 9. 如果最终实例是 A100-40GB + 5 核（当前截图）

这是可用的真实 A100，40GB HBM，比改显存 4090 更稳。

### 镜像

驱动 535.216.03，最高 CUDA 12.2，选：

```text
Python 3.11
PyTorch 2.4/2.5
CUDA 12.1
```

不要选 CUDA 12.4/12.8 的镜像。A100 计算能力应为 `(8, 0)`。

### 训练参数

只有 5 个 CPU 核，不能沿用官方 `num_workers=64`：

```bash
python train.py \
  --config-name=train_dinov2_bs192 \
  dataloader.num_workers=4 \
  val_dataloader.num_workers=2 \
  dataloader.prefetch_factor=2 \
  dataloader.persistent_workers=true \
  dataloader.batch_size=32 \
  val_dataloader.batch_size=16 \
  training.gradient_accumulate_every=4
```

- 先试 batch 32
- 稳定且显存有余量，再试 48
- 有效 batch 通过梯度累积到 128 左右
- 5 核下不要开 64 个 worker，否则 CPU 调度和内存都会出问题

### 评测

官方评测建议 16 核 / 64GB。5 核机器跑闭环评测会明显慢；
训练阶段可以忍，最终大规模评测建议换 16 核实例或单独评测节点。

### 存储

- 20GB 系统盘：只放代码和 Python 环境
- 50GB 数据盘：放数据、缓存、checkpoint
- `setup_server.sh` 已自动把缓存重定向到 `/hy-tmp`
- checkpoint 先设 `topk.k=2`，不要存 20 个
