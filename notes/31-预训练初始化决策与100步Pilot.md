# 预训练初始化决策与 100 步 Pilot（2026-10-19）

## 结论

主实验采用：

| 模块 | 初始化 | 训练 | 学习率 |
|---|---|---|---|
| DINOv2 ViT-S/14 | DINOv2 预训练 | 全量联合微调 | **1e-5** |
| CLIP 文本塔 | CLIP 预训练 | 冻结，只生成 `lang_emb` | — |
| DiT 动作头 | 从零 | 训练 | **1e-4** |
| view_proj / low_dim_net / fuse | 从零 | 训练 | **1e-4** |
| ChannelGate 12×384 | 从零 | 训练 | **1e-2** |
| DgCD / 动作重要性 | 无外部权重 | 在线统计/EMA | — |

一句话：

> **视觉和语言用预训练先验；动作头和小模块从零训练。**
> 这不等于“整个模型从零”，也不等于“全部冻结”。

## 为什么不是全冻结

CoRP 的直接对比：

| 视觉编码器 | LIBERO Avg |
|---|---:|
| Random ViT-S/14 | 78.1 |
| DINOv2 frozen | 77.2 |
| DINOv2 fine-tuned | **97.0** |

冻结几乎没有比随机初始化更好，说明机器人动作需要微调后的视觉特征。

## 代码修改

1. `optimizer.obs_encoder_learning_rate: 1.0e-5`
2. DINOv2 参数组单独设为 1e-5
3. `view_proj/low_dim_net/fuse` 保持主 lr 1e-4
4. 门控保持 1e-2
5. 新增消融开关：
   - `policy.dino_pretrained=false`：随机 ViT-S/14
   - `policy.freeze_dino=true`：冻结 DINOv2
   - `policy.dino_unfreeze_last_n_blocks=4`：只微调最后 4 个 block

验证后的优化器共 5 组：

```text
DiT decay      lr=1e-4
DiT no-decay   lr=1e-4
DINOv2         lr=1e-5
投影/融合层     lr=1e-4
ChannelGate    lr=1e-2
```

## 官方 DP checkpoint 兼容性

已从 hf-mirror 下载：

```text
/hy-tmp/checkpoints/robocasa_dp_pretrain_human300.ckpt
```

关键发现：

```text
model.cond_obs_emb.weight = (512, 969)
model.head.weight        = (12, 512)
```

因此官方 DiT 的 `cond_dim=969`。当前主实验 `feature_dim=256`，不能直接加载官方 DiT。

如果做 **warm-start 附加实验**，需要：

```yaml
policy.feature_dim: 969
```

然后只加载 checkpoint 中的：

```text
model.*
normalizer.*
```

跳过：

```text
obs_encoder.*   # ResNet18 权重，与 DINOv2 不兼容
_dummy_variable
```

实测结果：

```text
加载 277 个 model.* 参数
加载 46 个 normalizer.* 参数
missing 只有 obs_encoder.* 和 gate_bank.*
unexpected = 0
```

结论：

- **主实验：DiT 从零，与官方基线公平。**
- **附加实验：DiT warm-start，所有方法都必须同样 warm-start，否则不公平。**
- 当前 `feature_dim=256` 的配置不启用该 checkpoint。

## 100 步真实数据 Pilot

配置：

```bash
bash scripts/run_real_train.sh \
  dataloader.batch_size=32 \
  dataloader.num_workers=4 \
  val_dataloader.batch_size=8 \
  training.max_train_steps=100 \
  training.num_epochs=1 \
  training.lr_warmup_steps=10 \
  training.checkpoint_every=1000 \
  training.sample_every=100 \
  training.val_every=1000 \
  checkpoint.topk.k=1 \
  hydra.run.dir=/hy-tmp/runs/pilot100
```

结果：

```text
前 10 步平均 loss: 1.1478
后 10 步平均 loss: 0.3890
最终 action MSE: 0.2675
GPU 显存: 约 19–20GB / 40GB
速度: 约 2 秒/步
```

没有 `domain_id` 缺失警告。这个结果只用于验证训练通路，不是科学结论；LR 在 100 步内余弦退火到 0，loss 下降会偏乐观。

```bash
bash scripts/run_real_train.sh \

  training.checkpoint_every=1 \

  checkpoint.topk.k=2 \
```

注意：官方 workspace 的 checkpoint 条件是 `epoch > 0`，所以这里用 `num_epochs=20, max_train_steps=100`，每 100 步保存一次；不要用 `num_epochs=1` 期待保存。
