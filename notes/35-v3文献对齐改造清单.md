# v3 文献对齐改造清单（2026-10-19）

## 结论

当前 v2 只能作为机制探针：

- hard mask 工作；
- DP loss 正常；
- domain-balanced sampler 工作；
- DgCD per-sample 路径已跑通。

但 v2 仍然有五个“造轮子/弱化”点，不应作为最终主方法：

1. 动作重要性仍在 hard-masked 特征上估计；
2. consistency 是特征均值 MSE，不是预测级一致性；
3. domain/action 辅助权重仍是手调 `0.1`；
4. 层选择固定为 layer 11；
5. mask 仍是自研 top-k STE，不是 hard-concrete。

## v3 目标结构

```text
DINOv2（预训练 + 微调）
  -> 随机选 1 层
  -> 域分数：
       DgCD per-sample discrepancy
       或 DomainDrop domain classifier（消融）
  -> 动作分数：
       clean/pre-gate Taylor importance
       或 RSC 梯度分位数
  -> s = zscore(u) - λ * zscore(v)
  -> Hard Concrete / Gumbel-STE 生成 per-sample hard mask
  -> mask * numel / sum(mask) 重归一化
  -> gated/ungated 预测级一致性
  -> PCGrad / GradNorm / uncertainty weighting
```

## 实验矩阵（每组 200 步）

| 组 | mask | 域分数 | 动作重要性 | consistency | 权重 |
|---|---|---|---|---|---|

记录：

```text
domain score separation

consistency

```

## 判定门槛

只有以下条件都满足，才进入 2k：

- mask 丢弃比例接近配置值；
- 不同 style 的 mask IoU 明显低于同 style；
- `v_action` 不塌缩；
- gated/ungated 动作预测差异受控；
- DP loss 不被辅助项破坏；
- 各任务梯度余弦不是长期强负相关。

- clean Taylor 比 post-gate 更合理，但单独使用仍然让 v 偏小；
