## 0. 一张地图

一句话：

> 给机器人看几张图 + 一句指令 + 当前状态，让它输出一串动作；
> 难点不在"会做"，而在"换一个厨房还能做"。

这个"换环境"就是后面所有术语（domain shift / OOD / DG / corruption）的来源。

---

## 1. 机器人策略的四条技术路线

| 路线 | 代表 | 核心思想 | 规模 |
|---|---|---|---|
| 小 CNN 策略 | DP（Diffusion Policy）、ACT | 从零训练，便宜 | ~100M |
| **预训练视觉 + 紧凑动作头** | **CoRP（主基线）** | 好眼睛 + 小大脑 | 48.9M |
| VLA | π0、π0.5、OpenVLA、SmolVLA | 大 VLM/LLM 当大脑 | 0.5B–几十B |
| WAM | Cosmos-Policy、PICA-WAM | 先预测未来画面，再出动作 | 2B+ |

关键数字（LIBERO）：

```text
CoRP     48.9M  -> 97.0%
DP        157M  -> 72.4%
ACT        84M  -> 67.7%
π0.5      3.3B  -> 96.9%
Cosmos    2.0B  -> 98.5%
```

CoRP 的核心主张：

> **性能主要来自视觉表征，不是参数量。**

## 2. 泛化与鲁棒性的术语

类比：训练时见过 11–30 号厨房，测试时给 41–50 号厨房。

| 术语 | 含义 | 本项目对应 |
|---|---|---|
| i.i.d. | 训练/测试同分布 | 训练和测试同 style |
| OOD | 测试分布不同（out-of-distribution） | 测试 style 41–50 |
| domain（域） | 一组共享外观/环境的数据 | RoboCasa 的 style |
| domain shift | 训练域和测试域不同 | style 11–30 -> 41–50 |
| DG（Domain Generalization） | 只用源域训练，泛化到没见过的域 | 本项目在做的事 |
| style shift | 外观变了（颜色/纹理/材质） | RoboCasa style |
| semantic shift | 物体/任务变了 | 换任务 |
| corruption | 低层图像退化（模糊/噪声/分辨率） | Gaussian blur |
| source / val / test | 训练域 / 验证域 / 测试域 | 11–30 / 31–40 / 41–50 |
| held-out | 留出来、不参与训练的 | val/test style |
| success rate | 任务成功率 | 论文主指标 |
| ΔSR | 扰动后成功率与 clean 的差 | RoboCasa-Shift |
| matched pair | 同 episode、同初始状态，只改一个扰动 | RoboCasa-Shift 配对设计 |

关键区分（本项目踩过的坑）：

```text
style shift（语义外观）  -> CoRP 不退化（gap ~= 0，LIBERO-Plus 14/14）
corruption（低层退化）    -> CoRP 显著退化（blur sigma=2: 50%，sigma=4: 0%）
```

## 3. 域泛化方法（CNN 时代）

这些是 DomainDrop / PLACE / DgCD 的"祖先"。

| 方法 | 一句话 | 干预位置 |
|---|---|---|
| ERM | 普通训练（经验风险最小化） | 无 |
| RSC | 丢掉梯度最大的神经元，逼模型别只靠少数特征 | 梯度 |
| CORAL | 对齐不同域特征的二阶统计量 | 特征 |
| DANN | 域分类器 + GRL，让特征"分不出域" | 特征 + 梯度反转 |
| DomainDrop | 每个 stage 一个域分类器，丢掉"域敏感通道" | CNN 特征图 `(B,C,H,W)` |
| PLACE | 渐进加大 dropout 预算，丢通道或空间块 | CNN stage `(B,C,H,W)` |
| DgCD | 对抗地找"域差异最大的通道"，加权随机丢弃 | CNN 特征图 `(B,C,H,W)` |

共同点：

```text
都是 CNN 特征图 (B, C, H, W)
"通道" = 卷积通道 C
"空间" = H x W
```

## 4. ViT 时代的术语

| 术语 | 含义 | 本项目对应 |
|---|---|---|
| patch | 图像切成 14x14 的小块 | 224/14 = 16x16 = 256 块 |
| token | patch 经过 embedding 后的向量 | 256 个 token |
| CLS token | 分类用的全局 token | DINOv2 有，resampler 前丢弃 |
| channel / embedding dim | token 的维度 | **384** |
| attention head | 多头注意力的一个头 | DINOv2 有 6 个头 |
| LayerNorm | 每个 token 内部做标准化 | ViT 每个 block 都有 |
| pre-norm / post-norm | LayerNorm 在 block 前还是后 | DINOv2 是 pre-norm |
| resampler | 用 learned query 把 256 token 压成 48 | CoRP 的 K=48 |
| FiLM | 用语言向量调制 query 的 gamma/beta | CoRP 语言分支 |

最重要的映射：

```text
CNN 的 "通道 C"     ~= ViT 的 "embedding dim 384"
CNN 的 "空间 HxW"   ~= ViT 的 "token 256"
CNN 的 "conv stage" ~= ViT 的 "block 输出"
```

关键差异：

```text
CNN：通道 dropout -> 下一层 conv 还能重新混合
ViT：通道 dropout -> 下一层 LayerNorm 会重新标准化 -> mask 被部分抵消
```

这就是把 DomainDrop / PLACE / DgCD 搬到 ViT 上时效果变弱的原因之一。

## 5. ViT 上的域泛化方法（2023–2026）

arXiv 调研结论：主流几乎都在 **token 级**。

| 方法 | 时间 | 单位 | 做法 |
|---|---|---|---|
| TFS-ViT | 2023 | token | 混合不同域的归一化统计量（AdaIN 式） |
| SETA | 2024 | token | 语义感知 token 增强（扰动边缘、保留形状） |
| GNN-MoE | 2025-11 | patch | 用 GNN 路由 patch 到不同专家 |
| Causal-Tune | 2025-12 | feature | 分离视觉基础模型里的因果/非因果因子 |
| Later Is Better | 2026-10 | token | 分布偏移下 token reduction 的调度 |
| Stylizing ViT | 2026-01 | image | self/cross attention 做风格迁移 |

规律：

```text
ViT 的 DG 方法 = token-level / patch-level / statistics-level
channel-level gate 基本没人做
```

本项目代码里的 `dacsc/token_style.py`（AdaIN 式 token 统计量调制）就是 TFS-ViT 思路。

## 6. 生成式动作头的术语

| 术语 | 含义 |
|---|---|
| DDPM / diffusion | 从噪声一步步去噪，生成动作 |
| flow matching | 学一个速度场，把噪声"流"到动作 |
| rectified flow | 用直线路径的 flow matching（x(0)=noise -> x(1)=data） |
| tau | 流的时间步，0 -> 1 |
| velocity field | 模型输出的速度 v(x, tau) |
| Euler steps | 采样时用几步积分（CoRP 用 10 步） |
| 训练目标 | `v = x1 - x0`（data - noise） |

踩过的坑：

```text
第一版训练把方向写反了（target = noise - data）
-> train loss 下降，但采样动作 MSE 反而变差
```

## 8. 2025–2026 领域方向

1. **从"模型大小"转向"表征质量"**
   - CoRP：48.9M 追平 2–6B
   - 冻结 DINOv2 掉约 20 分，微调才有效

2. **从"静态 benchmark"转向"受控扰动 benchmark"**
   - LIBERO-Plus：7 维扰动，10,030 tasks
   - RoboCasa-Shift：4 因子 x 3 严重度，配对 rollout
   - LIBERO-VPro：闭环视觉鲁棒性

3. **从"域泛化"转向"corruption robustness"**
   - 语义外观偏移：模型已经比较鲁棒
   - 低层退化（blur/noise）：模型很脆弱

4. **从"大 VLA"转向"紧凑策略 + 强表征"**
   - CoRP、SmolVLA

5. **从"单帧"转向"世界模型"**
   - WAM、PICA-WAM

6. **表征对齐**
   - PICA-WAM：同一任务、不同外观 -> 一致的 action representation

## 9. 回到本项目

三个关键选择，每一个都依赖上面的概念：

```text
1. backbone = ViT（DINOv2）
   -> CNN 的 channel gate 不能直接搬
   -> ViT 的天然单位是 token

2. benchmark = RoboCasa365 style split
   -> 这是 semantic/style shift
   -> CoRP 不退化（gap ~= 0）

3. 真正会退化的是 corruption（blur）
   -> 这是 low-level image degradation
   -> 和 style shift 是两个不同的问题
```

核心矛盾：

```text
方法（channel gate）是为 CNN + style shift 设计的
主干（ViT）+ benchmark（style shift）不匹配
真正有退化的是 corruption（blur）
```

现有证据链（截至 2026-10-24）：

```text
RoboCasa style split（200 步）    -> gap -0.0179，无系统性退化
LIBERO-Plus 原生 7 类扰动         -> 14/14
论文 RoboTwin Randomized          -> -2.4 点
Gaussian blur sigma=2 / sigma=4   -> 50% / 0%（首个确凿退化）
RoboCasa adapted 模型 clean        -> 0/2（200 步太弱，note 68 已排除管线 bug）
```

结论：

> 语义/外观偏移不伤害 CoRP；低层图像退化才会。
> 方法目标应从 "domain/style generalization" 修正为 "low-level corruption robustness"。
