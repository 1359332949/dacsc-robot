## 环境踩坑与修复

| 问题 | 修复 |
|---|---|
| `diffusers.optimization` 缺 `Union` | 启动前 `import dacsc.compat` |
| 缺 `robosuite` | 安装 `robosuite==1.5.2` |
| 缺 `mujoco` | 安装 `mujoco==3.3.1` |
| `llvmlite` 版本被解析成 0.50 | 固定 `llvmlite==0.44.0` + `numba==0.61.2` |
| 缺 `gymnasium` | 安装 `gymnasium` |

| `wandb` 初始化等待 | `WANDB_MODE=disabled` |
| HuggingFace 不可达 | 从 ModelScope 拉 CLIP，本地路径加载 |
| `protobuf` 被 tianshou 降到 3.19 | 升到 `6.33.5` |
| 缺 `pyarrow` | 安装 `pyarrow` |
| 缺 `numpydantic` | 安装 `numpydantic` |
| 缺 `av` | 安装 `av` |
| 域标签类被 task 配置覆盖 | 把 `_target_` 直接写进 61 任务配置 |

## 训练验证

- `DomainLerobotCotrainingDataset` 生效
- 单条样本键：`obs, action, domain_id, layout_id`
- 示例：`domain_id=21`, `layout_id=45`
- action shape：`(10, 12)`
- 门控：12 层 × 384 = 4,608 个标量
- DINOv2 联合微调生效

### 20 步短训练（batch=8）

```text
loss: 1.2606 → 约 1.06
约 0.6–1.5 s/step（warmup 后）
```

### batch=32（推荐）

```text
峰值显存：约 20.2GB / 40GB
速度：约 3 s/step（warmup 后）
```

### batch=48

```text
峰值显存：约 27.9GB / 40GB
速度：约 5 s/step（warmup 后）
```

**结论：A100-40GB 上 batch=32 的吞吐和显存最平衡；batch=48 可跑但更慢。**

## 一键启动

```bash
cd /root/dacsc-robot
bash scripts/run_real_train.sh \
  dataloader.batch_size=32 \
  dataloader.num_workers=4 \
  val_dataloader.batch_size=8 \
  training.max_train_steps=20000 \
  training.checkpoint_every=1000 \
  policy.gate_init=0.9 \
  policy.gate_learning_rate=0.5 \
  policy.gate_rho_warmup_steps=100
```

正式训练前把 `gate_init`/`gate_learning_rate` 改回生产配置：

```yaml
gate_init: 0.999
gate_learning_rate: 1.0e-2
```

注意：短训练只设 `num_epochs=1` 时不会保存 checkpoint，因为官方 workspace 的 checkpoint 条件是 `epoch > 0` 且能被 `checkpoint_every` 整除；正式训练要设足够的 `num_epochs` 或调整保存逻辑。
