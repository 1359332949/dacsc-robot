# 前沿定位与方案区别（2026-10-16）

> 结论先行：**"DP 老了"的担心可以放下了。** 10 天前刚有一篇论文用 **48.9M** 的模型
> 追平了比它大 **40–163 倍**的系统，并论证**性能主要来自视觉表示**。那正是我们的战场。

---

## 一、三篇必须读的论文（都在最近 10 天内）

### ① `2610.08183` Compact Robot Policies Need Fine-Grained Visual Representations（2026-10-06）

**这篇最该读。它几乎是我们方向的"授权书"。**

- 提出 **CoRP**：**48.9M 参数**的刻意紧凑策略，**不用 VLM、不用视频生成先验**
- 分成两块：**视觉表示提取器 + flow-matching 动作生成器**
- 成绩：**LIBERO 97.0%**、RoboTwin 2.0 Clean/Randomized **75.78% / 73.36%**
- 原话：**"matching systems 40.9–163.6× larger"**（追平大 40–163 倍的系统）
- **核心论断：大部分性能差异来自视觉表示，参数规模和生成先验基本是次要的**
- **消融证据**（固定 action generator，只换视觉提取器）：
  - 随机初始化 ViT-S/14 → LIBERO 掉到 **78.1%**
  - **ImageNet ResNet-34 → 74.5%**
  - 即：**预训练初始化是关键**

**对我们的三点意义**：
1. **背书**："小模型也能打"，直接反驳"DP 太小/太老"
2. **定位**：它做的是"**换**哪个视觉提取器"；我们做的是"**在提取器内部按通道做域敏感性门控**" —— 互补，且它可作强引用
3. **提示**：它证明"预训练初始化是关键"→ **我们的门控应该作用在预训练过的表示上**。而我们的 DP fork 恰好支持 `get_resnet(weights="r3m")`（R3M 预训练 ResNet）！

### ② `2610.13024` What Visual Representations Do World Action Models Need?（2026-10-09）

- 系统比较**视觉表示 × 5 种集成机制 × 特征组合**
- 发现 1：**强通用视觉表示带来更广的鲁棒性收益**，能匹配甚至超过"为特定视觉能力预训练"的表示
- 发现 2：**channel-wise joint prediction 成功率最高** ← 注意 "channel-wise" 这个词
- 动机：WAM 的 VAE 表示是为**视觉重建**优化的，不是为**操作**优化的

**意义**：说明"视觉表示该选什么"已经是一个活跃的、有人在抢的方向。

### ③ `2610.05026` GeoBridge-VLA（2026-10-04）——**和我们的方法最接近，必须区分**

- 两阶段：**从预训练 VLA 的冻结视觉编码器里学几何特征**
  - Stage I：训练 feature bridge + geometry decoder（depth 监督）
  - Stage II：冻结上述模块，训练一个 **gated residual interface** + action projections
- 不加第二个图像编码器、不增加 token 数
- LIBERO **70.9%** vs SmolVLA **60.0%**；**禁用 residual 会掉点**

**和我们方法的差异（论文里必须写清）**：
| | GeoBridge-VLA | **我们（DACSC）** |
|---|---|---|
| 位置 | 编码器**输出之后**加 gated residual | 编码器**内部**，逐 conv block 的通道 |
| 粒度 | token 级 | **通道级** |
| 依赖 | 需要 depth 监督 | 只需要**域标签** |
| 目标 | 补几何信息 | **抑制域敏感通道、保护动作关键通道** |

### 另外两篇相关
- `2609.25506` **RoboMP-DINOv2**（09-22）：全场景 DINOv2 特征 + **masked-region color randomization (MCR)** 提升外观鲁棒 → 属**数据增广路线**，是我们的对比方法
- `2608.03231` **SARF**（08-04）：VLA 对抗补丁防御，**只微调部分层** → 说明"轻量适配视觉塔"是被认可的路

## 三、回答"视觉编码器是不是被固定了？大家都在研究什么？"

**要分两层看，这是你困惑的根源：**

| 层面 | 状态 | 大家在研究什么 |
|---|---|---|
| **VLA/WAM 主线** | **视觉塔基本固定**（预训练好、冻结或 LoRA，拿来当黑盒） | 研究**动作头**（flow matching / 自回归 token）、**数据**（多少、什么配比）、**世界模型**、**长时序/记忆**、**RL 后训练**、**推理速度** |
| **视觉表示这个方向** | **非常活跃** | ①**选什么表示**（2610.13024 做系统比较）②**怎么适配**（GeoBridge 的 gated residual、SARF 的部分微调）③**怎么鲁棒化**（RoboMP-DINOv2 的 MCR、TAPDreamer 的对抗补丁）④**小模型+好表示**（2610.08183 的 48.9M 追平大 163 倍）|

**所以你的困惑的来源是**：你看到的是"VLA 主线"，那里视觉编码器确实被固定了、不构成贡献；
但**正因为被固定，才有人专门去研究它** —— 而且这个方向刚刚被证明是"性能的主要来源"（①的结论）。

**一句话**：VLA 主线在研究"怎么用好一个固定的视觉塔"；而**我们在研究"这个视觉塔内部有什么问题、怎么修"**。后者不是过时，是**刚被证明重要**。

## 四、方案的由浅入深区别

### 第 1 层：三种"视觉编码器"的处置方式

| 方案 | 视觉编码器 | 训练什么 | 代价 |
|---|---|---|---|
| **A. 从零训小模型**（DP/ACT/CoRP） | ResNet18/34，**从零或 ImageNet 预览** | 全部 | 低（单卡 24–48 GB） |
| **B. 预训练 VLM + 冻结视觉塔**（SmolVLA） | SigLIP/SmolVLM2，**冻结** | 只训 action expert | 低（单卡） |
| **C. 预训练 VLM + 微调视觉塔**（π0/GR00T） | PaliGemma/Eagle-2，**LoRA 或全量** | 视觉塔 + action head | **高（H100/H200，80–100 GB）** |
| **D. 视频生成骨干**（WAM） | Wan2.2 VAE，**冻结** | 视频预测 + action | 极高（5B+） |

### 第 2 层：为什么"冻结视觉塔"会成为主流

因为**预训练太贵了**。SmolVLM2-500M 是在几十亿图文/视频对上训出来的；没人愿意为一个下游任务重训。
于是范式变成：**"冻结一个强大的表示 + 只学怎么用它"**。

这带来一个副作用：**视觉塔的内部结构不再被审视**。这正是研究空白。

### 第 3 层：我们的方法落在哪

我们的方法 **既不是 A 也不是 B/C** —— 它是一个**横切插件**：

```
方式 A/B/C/D 的差别在于「视觉塔怎么来、训不训」
我们的方法问的是「视觉塔内部的每一层每一个通道，对域变化敏不敏感」
       ↑ 这个问题与 A/B/C/D 都正交
```

**所以：**
- 在 **A（DP）** 上做 → 便宜、可解释、能做全部消融（**L1 主实验**）
- 在 **B（SmolVLA，冻结视觉塔）** 上做 → 证明"**不重训视觉塔也能提升**"，这是最强的论点（**L2 迁移**）
- 在 **C（π0）** 上做 → 需要 80–100 GB，暂时放弃

## 五、定位更新（基于新证据）

原判断"DP 是机制研究的显微镜"仍然成立，但要**加强两点**：

1. **加引用**：2610.08183 证明"性能主要来自视觉表示"，让我们的选题**正当性大幅提升**
2. **加一个 arms**：既然"预训练初始化是关键"（2610.08183 的消融），
   我们应该测 **R3M 预训练的 ResNet18**（我们的 fork 原生支持 `weights="r3m"`）——
   这可以成为门控的一个重要消融：**门控在"从零训"和"预训练"表示上的效果差异**

**更新后的实验设计**：

```
L0  CPU 机制验证                      （零成本）
L1  DP + ResNet18 全部消融            （单卡 24-48 GB）
L1b DP + R3M 预训练 ResNet18（新增）   ★ 回应 2610.08183 的发现
L2  SmolVLA + 冻结 SigLIP 视觉塔       （单卡）★ 最强论点
```
