## 0. 先澄清一件事：我们的 base 是 Diffusion Policy，不是 RoboSaGA

| | 是什么 | 在我们实验中的角色 |
|---|---|---|
| **base（已锁定）** | RoboCasa 官方 Diffusion Policy fork：`robocasa-benchmark/diffusion_policy` + `robomimic@robocasa-dp` | 所有方法共用的骨架。视觉编码器 `ResNet18ConvFiLM`（8 个 conv block，逐 block 语言 FiLM），`H=10 / n_obs=2 / n_action=8`，DiT 12 层 |
| **RoboSaGA** | `zheyu-zhuang/RoboSaGA`，**CoRL 2024** 的显著性引导增广 | **对比方法**（数据增广路线），不是 base |

RoboSaGA 容易记混的原因：它在 **2026-08-12** 才挂到 arXiv（`2608.11870`），容易被误当成 2026 年的新工作。我核对了 arXiv 页面：

```
标题: Enhancing Visual Domain Robustness in Behaviour Cloning via Saliency-Guided Augmentation
作者: Zheyu Zhuang, Ruiyu Wang, Nils Ingelhag, Ville Kyrki, Danica Kragic
Comments: Accepted at the Conference on Robot Learning (CoRL) 2024
Journal ref: CoRL 2024
Submitted: 12 Aug 2026
```

**结论：这是一篇 CoRL 2024 的方法，2026-08 才补挂 arXiv。** 论文里如果把它当"2026 最新工作"引用会被抓；反过来，这对我们是好消息——说明"机器人策略的**通道/特征级**域泛化"这条路已经两年没人碰了。

### RoboSaGA 的代码结构（省掉 680MB 的依据）

680MB 里 1031MB 是**内嵌的 robosuite**（含 4K 纹理和 mesh）。真正的方法代码只有：

```
robosaga/robosaga/saliency_guided_augmentation.py   14.9 KB   ← 核心方法
robosaga/robosaga/background_randomizer.py           3.7 KB
robosaga/robosaga/buffer_manager.py                  5.2 KB
robosaga/robosaga/custom_group_norm.py               1.5 KB
robosaga/robosaga/fullgrad.py                        4.7 KB   ← 显著性全梯度
robosaga/robosaga/resnet.py                         39.5 KB
robosaga/robosaga/soda.py                            5.7 KB   ← SODA 对比方法
robomimic/robomimic/scripts/generate_robosaga_configs.py  6.2 KB
robomimic/robomimic/scripts/train_soda.py           18.2 KB
robomimic/robomimic/scripts/eval_visual_domain_shifts.py  6.6 KB  ← ★视觉域偏移评测脚本
diffusion_policy/.../diffusion_unet_hybrid_image_policy_soda.py  14.8 KB
diffusion_policy/.../config/train_diffusion_unet_hybrid_*_image_{saga,soda,overlay}.yaml  12 个
robomimic/robomimic/robosaga_configs/**/*.json      30 个配置
backgrounds.zip                                     27.5 MB  ← OOD 背景图池
```

只抓这些 ≈ 30MB，而且 `eval_visual_domain_shifts.py` 的评测协议可以直接借鉴到我们的 style-holdout 评测。

**两个必须注意的技术点**：
1. RoboSaGA 的 README 明确写了它相对论文做了改动：**用 Average Pooling 替换 Spatial Softmax**，理由是 Spatial Softmax 的梯度依赖坐标网格常数，会引入菱形梯度先验、损害显著性估计。而**我们的 base 恰好用的就是 `SpatialSoftmax(num_kp=32)`** —— 这条直接影响我们门控信号的质量，值得在阶段 2 复现时验证。
2. 它的实验数据集是 **robomimic（can/lift/square/transport）**，不是 RoboCasa365。迁移到我们的场景需要重建增广管线和域划分。

## 7. 六个坑（写论文/建仓库前必须知道）

### 坑 1：DRAIL 同名冲突 ⚠️

你文档参考文献 9 的 DRAIL = **"Dual-Region Augmentation for Imitation Learning"**（农业操作，arXiv 2603.04845）。
但 GitHub 搜 "DRAIL" 排第一的是 **[NVlabs/DRAIL](https://github.com/NVlabs/DRAIL) = "Diffusion Rewards Adversarial Imitation Learning"（NeurIPS'24，arXiv 2405.16194）** —— 完全不同的论文、不同领域。

**两条提醒**：① 别下错仓库；② 农业版 DRAIL 我**没找到公开代码**（GitHub 检索无结果），所以它是"无代码对比方法"，只能文字引用。

### 坑 2：RoboSaGA 无 license

仓库没有 LICENSE 文件（GitHub API 返回 `license: null`）。研究对比可以用，但**把它的代码复制进我们仓库对外发布有法律风险**。建议只做本地对照，仓库里放脚本去 clone/抓取，不 vendor。

### 坑 3：RoboVIP / RoboAug 都是"半发布"

- RoboVIP：权重+推理代码有，**仿真训练和评测未发布**（README TODO 未勾）
- RoboAug：只有数据生成（stage 1-2），**region-contrastive 损失未开源**（只能自己按论文实现）

### 坑 4：RoboSaGA 的 DP 支持没测过

README 的 TODO：`🔳 Test training and evaluation scripts for Diffusion Policy`（未勾），已测的只有 BC-MLP / BC-RNN。所以"RoboSaGA + Diffusion Policy"这个组合**需要我们自己跑通并验证**，不能直接引用它的 DP 数字。

### 坑 5：RoboSaGA 改过方法（相对论文）

README 的 Update 段：**用 Average Pooling 替换 Spatial Softmax**（论文里是 Spatial Softmax）。我们的 base 用的是 SpatialSoftmax(32)，所以**不能照抄**，要自己决定用哪个。

### 坑 6：许可不明确的仓库

`robocasa/robocasa`、`robocasa-benchmark/mimicgen`、`robocasa-benchmark/leaderboard` 的 license 是 `NOASSERTION`（代码 MIT、资产/数据 CC BY 4.0，README 有说明）。数据资产 10GB+，注意磁盘。

## 9. 一句话结论

我们的 **base 是官方 Diffusion Policy**（不是 RoboSaGA）。RoboSaGA 是**对比方法**，而且是 **CoRL 2024** 的老方法（2026 才挂 arXiv）。真正值得拉的对比代码是 **RoboEngine（最成熟，MIT，27.5MB）** 和 **RoboAug（最新，CoRL2026，但半发布）**；RoboSaGA 只需抓 ~30MB 的核心源码。另外，**官方 checkpoint 已公开，阶段 1 可以不训练就跑通评测**，这应该能省掉大量时间。
