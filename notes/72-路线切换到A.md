# 72 - 路线切换：回到 A（style/appearance shift）

日期：2026-10-24
决策：**采用 A（style/appearance shift）作为主问题**，B（low-level corruption）降为辅助证据。

---

## 1. 为什么必须先补一个前提实验

A 的原始假设是：

```text
style/appearance shift -> 策略退化
```

但现有证据**不支持**这个前提：

```text
RoboCasa365 style split (11-30 vs 31-40 vs 41-50)
  -> source 0.1618 / val 0.1548 / test 0.1574，median gap -0.004（无退化）
LIBERO-Plus 原生 style/light/background 扰动（14/14 小样本）
  -> 全部成功
```

**结论**：当前 LIBERO-Plus 的 appearance 偏移太弱，CoRP 不受影响。

所以 A 路线的第一步不是实现 gate，而是：

> **构造一个受控的、足够强的 appearance shift，先确认它能把 CoRP 打崩。**

否则 A 会重蹈“前提不成立、方法空转”的覆辙（根因 1）。

---

## 2. 更新后的研究合同（A 版）

### Q1. 问题

```text
A：style/appearance shift（颜色、对比度、灰度、色调、纹理/背景）
```

### Q2. Claim（待验证）

```text
在 compact flow-matching robot policy（CoRP）上，
action-aware channel-level gating 能提升 appearance shift 下的动作成功率，
且不损害 clean 性能。
```

### Q3. 对照

```text
no-gate
random-channel（强制）
DBCT/SCS-style channel suppression
TFS-ViT-style token statistics
ours = channel gate + action-aware protection
```

### Q4. Kill criteria

```text
K0. appearance shift 本身不造成退化 -> 前提不成立，A 停（写负结果）
K1. clean success < 50% -> 先修 baseline
K2. ours <= random-channel（3 seeds 同向）-> 负结果，停
K3. 3 seeds 不一致 -> 加样本，不扩方法
K4. 只有 aggregate MSE -> 不声称有效/无效
```

---

## 3. 第一步实验：受控 appearance shift

在 LIBERO-Plus（或标准 LIBERO）上，对**同一批 task、同一初始状态、同一 seed**
额外施加 appearance shift，测 CoRP success rate：

```text
none（已在 LIBERO-Plus clean 上 72.9%）
grayscale
color jitter（brightness/contrast/saturation/hue）
low contrast
hue shift
```

验收：

```text
若 none -> grayscale/color jitter 出现显著下降
  -> A 前提成立，进入 P3（u/v 审计）和 P4（channel gate）
若不下降
  -> A 前提不成立，A 只能写成负结果
```

**注意**：与 blur（low-level）不同，这里的 shift 必须是 **appearance 语义维度**，
不能靠 blur/noise 来"制造"退化，否则又滑回 B。

---

## 4. 后续顺序

```text
1. 受控 appearance shift 评测（先验证前提）
2. 若成立 -> P3 机制审计（u/v 重叠、register neuron、neuron path）
3. P4 最小 channel gate（action-aware）
4. 对照：no-gate / random / DBCT-SCS / TFS-ViT / ours
5. P5 决策树（预注册）
```

## 5. 红线（A 版）

```text
1. 不先验证 appearance shift 是否造成退化，不写 gate
2. 不用 blur/noise 冒充 appearance shift
3. 不做 fidelity 表，不用官方方法名
4. 没有 random-channel 对照，不下结论
5. 少于 3 seeds / 200 步，不声称有效
6. 只有 aggregate MSE，不声称有效/无效
7. train-only 和 inference-time 不混用
8. 不在 200 步弱模型上测 success rate
```
