# DACSC-Robot 方法、理论依据与实现总览

> 2026-10-17。本文把「问题 → 洞察 → 方法 → 理论依据 → 实现 → 证据」串成一条线。
> 标注说明：**【已有】** = 论文/开源代码已验证；**【借鉴】** = 别人的方法改造；
> **【候选】** = 我们的组合设计，待实验验证；**【假设】** = 目前无直接证据。

---

# 第一部分：问题（最浅的一层）

## 1.1 现象

机器人用摄像头学做家务。训练时的厨房是固定的（同一种台面、墙色、灯光）。
换个厨房（台面变大理石、灯光变暖、多了杂物）→ **动作就乱了**。

## 1.2 为什么（一个可验证的解释）

神经网络看图不是一个整体判断，而是几百个**通道**并行处理。
训练时没人告诉每个通道该学什么，它自己长出来。

**关键事实【已有】**：DomainDrop（ICCV 2023）观察到——
> 训练好的模型里，存在大量"**在不同域之间激活不稳定**"的通道。
> 这些通道倾向于捕获域特异特征，遇到新域时行为异常。

**所以**：模型很可能把"台面木纹"这种**随环境变、与任务无关**的通道，
误当成了"该伸手"的依据。

## 1.3 我们的目标（一句话）

> 找出**对域变化敏感、但对动作不重要**的通道，抑制它们；
> 同时**保护对动作重要的通道**；被抑制的信息用少量任务相关特征补偿。

**注意这里有两个条件（"且"）**——这是全方法的支点：
只按"域敏感"删会误伤（比如"白色杯子"的白色既是外观也是任务），
只按"动作重要"留则等于什么都没做。

# 第二部分：核心洞察（方法的立意）

## 2.1 三个不同性质的通道

| 通道类型 | 对域敏感？ | 对动作重要？ | 该怎么做 |
|---|---|---|---|
| 纯噪声/背景纹理 | **高** | 低 | **抑制** |
| 物体位置/形状 | 低 | **高** | **保留** |
| 物体颜色（既是外观又是任务线索） | 中 | 中 | **保留 + 补偿** |

**我们的方法就是在学这张表**：用两个可计算的信号去近似"敏感"和"重要"。

## 2.2 为什么用"软门控"而不是"硬删除"

- **硬删除**【已有做法】：DomainDrop 直接丢弃 33% 的通道（二值掩码）。
  问题：① 不可逆，删错了没法救；② 训练/推理行为不一致（随机丢弃只在训练时）。
- **软门控**【我们的选择】：每个通道一个可学习的开度 \(g\in(0,1)\)，
  输出 \(F\odot g\)。好处：
  ① 可微，端到端学；② 推理确定；③ 能精确控制"平均抑制多少"。

**代价**：需要额外的正则项告诉它"该关多少"，否则它会全部关掉或全不关。
→ 这就是门控目标 \(L_{\text{gate}}\) 存在的原因。

# 第三部分：方法（四步）

## 3.1 全流程

```
① 计算域敏感性 u          （这个通道"随环境变"的程度）
② 计算动作重要性 v        （这个通道"对预测动作"的重要程度）
③ 训练门控 g = σ(η)      （用 u 和 v 共同决定每个通道开度）
④ 动作一致性约束          （换外观后动作应当一致）
```

## 3.2 ① 域敏感性 \(u^{\text{disc}}\) —— 用 DgCD 的官方做法

**【已有，移植自 gyeomo/DgCD（CIKM 2024, MIT）】**

我们**不用**"逐通道高斯 KL"（早期文档写错了，已修正）。官方做法是：

1. 对特征做 GAP → 逐通道向量 \(V\in\mathbb R^{B\times C}\)
2. 按域标准化，再乘可学习仿射（\(\gamma,\beta\)）
3. **对通道维做 log-softmax** → 把"通道向量"当成一个概率分布
4. 用 KL 比较"全体分布"与"各域分布"
5. **对抗步**：对这个 KL 求梯度，**对仿射参数做梯度上升**（主动找最坏对齐）
6. 用更新后的仿射重算 → 打分量用**平方差**（不是 KL）：

\[
s_{b,c} = \left(Z^{\text{all}}_{b,c} - Z^{\text{env}}_{b,c}\right)^2
\]

7. 对 batch 求均值 → \(u^{\text{disc}}_{l,c}\)

**为什么这么做能识别域敏感通道**：如果一个通道的值在不同域之间系统性不同，
那么"总体分布"与"按域分开后的分布"就会不一致 → 分数高。

## 3.3 ② 动作重要性 \(v^{\text{Taylor}}\)

**【借鉴，Taylor 一阶结构重要性（Molchanov et al., CVPR 2019）】**

\[
v^{\text{Taylor}}_{l,c} = \text{EMA}\left(\left|\bar f_{l,c}\cdot \frac{\partial \mathcal L_{\mathrm{DP}}}{\partial \bar f_{l,c}}\right|\right)
\]

**直觉**：把通道关掉一点点，动作损失会变多少？一阶近似就是"激活 × 梯度"。
分数高 = 这个通道对预测动作影响大 = **不能动**。

**实现细节**（关键）：门控后的激活要 `retain_grad()`，在 `backward()` 之后读取 `.grad`，
再 EMA 累积。这要求"上一轮的图"能留到下一轮读——我们复用了 DgCD/RSC 的同款技巧。

## 3.4 ③ 门控目标 \(L_{\text{gate}}\)

**【候选组合】** 这是我们自己拼的，不是任何原文的公式：

\[
\mathcal L_{\text{gate}} =
\underbrace{\frac{1}{LC}\sum_{l,c}\lambda_d\, u_{l,c}\, g_{l,c}}_{\text{抑制域敏感}}
+ \underbrace{\frac{1}{LC}\sum_{l,c}\lambda_a\, v_{l,c}\,(1-g_{l,c})^2}_{\text{保护动作重要}}
+ \underbrace{\lambda_\rho\left(\frac{1}{LC}\sum_{l,c}(1-g_{l,c})-\rho\right)^2}_{\text{控制抑制预算}}
\]

**逐项的梯度方向（为什么这样写有效）**：

| 项 | 对 g 的梯度 | 效果 |
|---|---|---|
| \(\lambda_d u g\) | \(+\lambda_d u\) | u 越大 → 梯度越正 → 梯度下降让 **g 变小**（抑制）✓ |
| \(\lambda_a v(1-g)^2\) | \(-2\lambda_a v(1-g)\) | g 越偏离 1，阻力越大（二次惩罚）→ **别乱关** ✓ |
| 预算项 | — | 把"平均抑制比例"钉在 \(\rho\) ✓ |

**注意保护项在 g≈1 时梯度为 0**：它不主动把 g 拉回 1，而是**越关越贵**。
这是刻意的——避免与域敏感项在初始化时互相抵消。

**渐进预算**【借鉴 PLACE 的思想】：

\[
\rho(t) = \rho_{\max}\left(\frac{t}{T_{\text{warmup}}}\right)^p
\]

先不抑制，随着训练逐步放开，避免一开始就把重要通道关掉。

## 3.5 ④ 动作一致性 \(L_{\text{cons}}\)

**【候选，与 PAIR-VLA（2026）思路重叠，需差异化】**

同一个动作、同一场景，只改外观（\(o_t\) vs \(o_t^+\)），要求噪声预测一致：

\[
\mathcal L_{\text{cons}} = \left\|\epsilon_\theta(x_k,o_t,s_t,k) - \epsilon_\theta(x_k,o_t^+,s_t,k)\right\|^2
\]

**为什么放在"噪声预测空间"而不是"最终动作"**：
动作经过采样后噪声大、梯度差；噪声预测是网络直接输出，信号更干净。

**实现前提**：需要"同场景换外观"的反事实对。RoboCasa365 支持——
读入某 episode 的 `ep_meta.json`，**只改 style_id、保持 layout 与物体不变**，重置环境即可。
（这是选 RoboCasa365 的核心理由之一。）

# 第四部分：理论依据（哪条是硬的、哪条是软的）

## 4.1 硬依据（有论文/实验支撑）

| # | 依据 | 来源 | 强度 |
|---|---|---|---|
| 1 | 训练好的网络含大量"域间激活不稳定"的通道，它们捕获域特异特征 | DomainDrop, ICCV'23 | **强**（有可视化与消融） |
| 2 | 抑制这类通道能提升域泛化 | DomainDrop / PLACE / DgCD | **强**（三篇独立工作） |
| 3 | 用"表示梯度"定位重要维度是有效做法 | RSC, ICLR'20；Taylor pruning, CVPR'19 | **强** |
| 4 | **任务感知的压缩 > 任务无关的压缩** | CoRP, 2026（4.6 节：97.0 vs 83.2） | **强**（受控实验） |
| 5 | 小模型 + 好视觉表示可追平 40–163× 大模型 | CoRP, 2026（4.3 节） | **强** |
| 6 | 视觉表示（而非参数量）决定鲁棒性 | CoRP 4.2：DP 在 Randomized 下崩到 0.6% | **强** |

**其中第 4 条是对我们最有利的类比**：
CoRP 证明了"按指令有选择地压缩"远好于"无差别压缩（VIB）"。
我们的门控正是"**按域标签有选择地抑制**" vs "无差别 Dropout"——逻辑同构。

## 4.2 软依据（合理但未被直接验证）

| # | 主张 | 现状 |
|---|---|---|
| 1 | "域敏感 ∧ 动作不重要"的通道确实是可以安全抑制的 | **【假设】** 直觉合理，但没有直接证据 |
| 2 | 两个分数线性融合（\(\alpha,\beta\)）是合适的 | **【假设】** 权重靠实验选 |
| 3 | 软门控能学到"该关哪些" | **【候选】** 我们只在合成数据上验证了通路，没验证效果 |
| 4 | 反事实一致性约束能提升闭环成功率 | **【候选】** 与 PAIR-VLA 重叠，需实验区分 |
| 5 | 这些在 RoboCasa365 上有效 | **完全未验证**（数据还没到） |

## 4.3 诚实的一句话

> **"通道级域敏感性 + 动作重要性"的组合是我们的候选创新，逻辑自洽但尚未被实验证明。**
> 已被证明的是它的每个零件（DomainDrop 的通道假设、RSC 的梯度重要性、CoRP 的任务感知压缩）。

# 第五部分：实现（代码怎么落的）

## 5.1 分层结构

```
数据层   dacsc/dataset.py       从 extras/ep_meta.json 读 style_id / layout_id
         dacsc/stub_dataset.py  合成数据（外观依赖域、动作不依赖域）
              ↓ batch: {obs, action, domain_id, layout_id}
编码器   dacsc/dinov2_encoder.py  DINOv2 ViT-S/14，多视角共享权重，12 层 × 384 维
              ↓ (B*To*V, 257, 384)
门控     dacsc/gating.py        12 个 ChannelGate 挂在 block 输出（forward hook 注入）
              ↓
打分     dacsc/dg_methods.py    DgCDScorer（u^disc）、rsc_grad_mask、coral_loss
         dacsc/domain_stats.py  模式分发：dgcd / kl_gauss
              ↓
条件     policy.py: mean-pool → 投影 → DiT 的 cond (B, To, 256)
              ↓
去噪     TransformerForDiffusion（官方，未改）
              ↓
损失     dacsc/losses.py        L_gate + v^Taylor + CORAL
         policy.py: L_total = L_DP + L_gate (+ λ_coral·L_CORAL)
```

## 5.2 一次训练步的完整时序

```
1. 取 batch（含 domain_id）
2. 前向：
   - DINOv2 的 12 个 block 依次执行，每个 block 后被 hook 乘上门控 g
   - hook 同时把"门控前"激活存进 _collect（供域统计）
   - patch token 均值池化 → 投影 → DiT 的 cond
   - DiT 预测噪声 → L_DP
3. 域统计：对 12 层分别调用 DgCDScorer → u^disc (12, 384)
4. 门控正则：L_gate = λ_d·u·g + λ_a·v·(1-g)² + λ_ρ·(预算偏差)²
5. L_total = L_DP + L_gate
6. backward → 门控后激活的 .grad 被保留（供下一轮算 v）
7. optimizer.step()（4 个参数组：DiT-decay / DiT-no-decay / 编码器 / **门控**）
8. EMA 更新
```

## 5.3 关键工程决策（都是踩坑后定的）

| 决策 | 为什么 |
|---|---|
| **不改官方文件** | 继承 `DiffusionTransformerHybridPolicy`，只重写 `__init__` 和 `compute_loss` |
| **forward hook 注入门控** | 不改 DINOv2 源码；hook 返回张量即可替换输出 |
| **门控 lr = 1e-2（主 lr 的 100×）** | g=σ(η) 在 0.999 处饱和，σ'≈1e-3，否则 g 空间每步只动 1e-7 |
| **DgCD 打分就地算、不缓存激活** | 12 层缓存 ≈ 113 MB/步，16GB 机器会换页 |
| **打分时显式 `enable_grad`** | DgCD 的对抗步需要梯度，`@no_grad` 会直接报错 |
| **域标签按 (B×To×V) 展开** | 编码器把 batch、时间步、视角三个维度合并了 |
| **加标签对齐安全网** | extras 序号若与 episode_index 错位，标签会整体张冠李戴且**不报错** |

# 第六部分：目前有什么证据

## 6.1 已验证（本机 CPU/MPS）

| 项 | 结果 |
|---|---|
| 官方 DP 基线 | 106.03 M 参数，`action [1,8,12]` ✓ |
| DINOv2 编码器版 | 85.84 M，比官方小 19%，**梯度能流到 DINOv2**（联合微调生效）✓ |
| 恒等门控 | 相对差 **5e-06**（注入无害）✓ |
| 门控规模 | 4608 个标量，占 0.0054% ✓ |
| DgCD 打分性质 | **真有域差异的通道得分高 1.43×** ✓ |
| CORAL / RSC / GRL | 与官方行为一致 ✓ |
| 域标签读取 | 7 项测试含"错位能被检出" ✓ |
| 端到端训练 | `kl_gauss` 8 步 18.5s；`dgcd` 4 步 29.1s ✓ |

|---|---|

# 第七部分：一句话总结（三层）

| 深度 | 一句话 |
|---|---|
| **最浅** | 找出视觉网络里"爱看装修、不管干活"的零件，把它们调小。 |
| **中间** | 用「跨域分布差异（DgCD）」定位域敏感通道，用「梯度重要性（Taylor/RSC）」保护动作关键通道，用「可学习软门控 + 抑制预算」实现抑制，用「换外观动作一致」约束输出。 |
| **最深** | 把域泛化从"换一个更强的表示"变成"在固定表示内部做**任务感知的通道级裁剪**"；其理论依据是"域敏感性与任务重要性可分离"这一假设，而该假设的每个零件都有独立文献支持，但**组合尚未被验证**。 |
