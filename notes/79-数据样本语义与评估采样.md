# 79 - 数据样本语义与评估采样（澄清）

日期：2026-10-24

## 1. 数据集 vs 训练样本

```text
数据集：每个 episode 是完整视频（~100–300 帧）
训练样本：当前 1 帧 × 3 视角 + 未来 10 步动作
不是：整个数据集只有 1 帧
```

`CorpRoboCasaDataset.__getitem__` 返回：

```text
images[view]: [3, 224, 224]     # 当前帧
state:        [9]
action:       [10, 12]          # a_t .. a_{t+9}
instruction:  str
style_id:     int
task:         str
```

## 2. 为什么是 1 帧

```text
CoRP 架构：visual_encoder 输入 [B*V,3,224,224]，无时间维
-> 单帧/视角（忠实 CoRP）
RoboCasa DP：n_obs_steps=2（当前 + 上一帧）
```

**这是一个设计差异，不是 bug。**
公平比较必须二选一：

```text
A. CoRP 和 DP 都用 1 帧
B. CoRP 和 DP 都用 2 帧（CoRP 需要加时间维）
```

不能一个 1 帧、一个 2 帧直接比。

## 3. 评估采样（balanced_indices）

```text
per_style = max(1, per_task_eval // n_styles)
source: 20 styles -> per_task_eval=8  时每 style 1 帧，共 20 帧/task
val:    10 styles -> per_task_eval=8  时每 style 1 帧，共 10 帧/task
```

好处：style 均衡。
坏处：每 task 样本少（10–20 帧），per-task MSE 噪声大。

**最终评估建议**：

```text
per_task_eval >= 40
  -> source: 2 帧/style × 20 = 40 帧/task
  -> val:    4 帧/style × 10 = 40 帧/task
```

## 4. 训练步数的含义

```text
steps_per_epoch = floor(501594 / batch)
200 步 × batch 16 = 3,200 样本 = 0.64% epoch
官方 CoRP：80k × batch 392 = 31.36M 样本
比例：约 1/9,800
```

200 步只能叫 smoke。
