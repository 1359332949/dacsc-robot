## 三、🔴 重大发现：我们的方法文档 §6.4 **写错了 DgCD**

### 文档 §6.4 写的是

> 对于域 d，估计通道激活的**高斯近似** q = N(μ, σ²)；
> 定义 u^disc = (1/|D|) Σ_d KL( q_d ‖ q_* )

（文档当时自己标注了"待按原文核对"，现在核实：**与官方实现不符**）

### DgCD 官方代码实际做的是（`networks/DgCD.py`，99 行）

1. 对特征做 GAP 得到 `V ∈ R^{B×C}`
2. **`alignment()`**：按"环境"（batch 切成 32 一块）与全体分别做 mean/var 标准化，
   再乘上**可学习的逐 (样本,通道) 仿射** `Scaling(β, γ)`
3. 对**通道维**做 `log_softmax` → 把"通道向量"当成一个概率分布
4. `KLDivLoss(log_target=True)` 比较"全体分布"与"各环境分布"
5. **`dist.backward()` + 对 scaler 做梯度上升**（Eq.7-8）→ **对抗式地把差异拉大**
6. 用更新后的 scaler 重算 alignment
7. `gram = diag(mm(总.T, 环境))` → 归一化
8. **`scores = (总 − 环境)²`**（Eq.11）→ 逐通道的**平方差**，**不是 KL**
9. min-max 归一化 → **加权随机采样（WRS）**`key = r^(1/scores)` → 丢 `ratio` 比例
10. **掩码重归一化**：`mask * numel / sum` ← **保持量级**（这一步很关键，容易漏）

**所以三处实质差异**：
| | 文档写法 | DgCD 实际 |
|---|---|---|
| 分布形式 | 逐通道**高斯** KL | **通道维 softmax** 分布 |
| 打分 | KL 散度 | **平方差**（KL 只用来驱动对抗 scaler） |
| 对抗性 | 无 | **有**（梯度上升拉大差异） |

**必须做的事**：修方法文档 §6.4，要么按官方改写描述，要么明确标注"我们自研的简化变体"。

## 四、DomainDrop 官方实现（可读但无许可）

`models/FilterDropout.py` + `models/LayerDiscriminator.py`，共约 140 行：

```python
# 打分公式（与论文一致，我们之前核对过）
weights = self.model.weight.clone().detach()        # (num_domains, C)
weight  = weights[labels].view(B, C, 1, 1).expand(...)
right_score = feature * weight                      # s_j = W^{y_d}_j · f_j
right_score = self.norm_scores(right_score)         # min-max 归一化
```

**丢弃**用加权随机采样（WRS）：
```python
r = torch.rand(scores.shape)
key = r.pow(1. / scores)                            # Eq.12
threshold = torch.sort(key, dim=1, descending=True)[0][:, int(ratio*C)]
mask = 1 - (key > threshold)                        # Eq.13
```

还有 **GRL（梯度反转层）** 的实现（`GradReverse`），也可借鉴。

⚠️ **无 license**：不能直接复制进我们仓库，但可以**照逻辑重写**（算法本身不受版权保护）。

## 六、移植 DgCD 需要注意的坑

1. **硬编码 `.cuda()` 和 `device="cuda"`** → 要改成设备无关（我们本机跑 MPS）
2. **`Scaling` 的参数维度是 `(batch_size, channels)`** → 参数依赖 batch 大小，很反常；
   需要我们决定"每次前向重建"还是改成与 batch 无关的形式
3. **环境切分写死 32** → 我们的设定里一个 batch 含多个域，应按**域标签**切分而不是按 32 切
4. **`make_mask` 的掩码重归一化**（`mask * numel / sum`）容易漏，漏了会整体缩小激活
5. 它是**硬掩码**（0/1 乘），我们是**软门控**（σ(η)）—— 这是我们的贡献点，要保持区分

## 七、一句话总结

> **别人造过的轮子：DgCD 打分（MIT）、RSC 梯度屏蔽（MIT）、CORAL（MIT）、40 个域泛化算法（MIT）。**
> **别人没造的轮子：把"域敏感通道识别"用在机器人视觉策略的**软门控**上，并用 Diffusion Policy 去噪损失做动作保护。**
>
> 所以策略是：**接口和打分抄现成的，创新点（软门控 + 动作保护 + 机器人闭环）自己做。**
