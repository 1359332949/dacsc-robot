## 三、实现要点

### ① 门控插在哪：DINOv2 的 12 个 block 输出

```
图像 → patch_embed → [block 0] → ★gate → [block 1] → ★gate → ... → [block 11] → ★gate → norm → patch token
```

**为什么是隐藏维度（384）而不是 token**：
CNN 里"通道"= 一张空间特征图；ViT 里语义对应物是 **token 的隐藏维度**
（一个隐藏维度在所有 token 上共享同一语义）。这与 DomainDrop / PLACE 的"通道"概念可直接对应。

### ② 怎么插：forward hook，不改 DINOv2 源码

hook 返回张量即可**替换**该模块输出 —— 所以门控可以完全外部化：
```python
def hook(module, inputs, output):
    return gate(output)        # 替换输出
blocks[i].register_forward_hook(hook)
```

### ③ 三段式闭合：域敏感性 → 门控 → 正则

```
前向时  : hook 收集每层"门控前"激活 → DomainActivationStats 按 style_id 累计
每次 loss: u^disc（KL 域敏感性）→ gate_regularizer（抑制域敏感 + 保护动作重要 + 预算）
反向时  : 门控后激活 retain_grad → 下一轮读梯度 → v^Taylor 动作重要性
```

### ④ 踩过并解决的 4 个坑

| # | 坑 | 解法 |
|---|---|---|
| 1 | 测试①用"两份独立策略"对比 → 随机初始化不同，测出差 6.28 | 改成**同一策略装/拆 hook**对比 |
| 2 | 扩散采样是**随机的** → 两次调用结果天然不同 | 两次调用固定同一随机种子 |
| 3 | 域标签维度不匹配：编码器把 `(B,To)` 和视角维都合并成 `B*To*V` | `did.repeat_interleave(To * V)`，并加长度兜底 |
| 4 | 测试③两个"域"用了不同随机图像 → 区分度被淹没 | 改**受控对比**（同图只改颜色） |

### ⑤ 还没做的（下一步）

| 项 | 说明 |
|---|---|
| **数据集提供域标签** | 官方 `LerobotDataset` 不含 `style_id`，需要读 `extras/episode_*/ep_meta.json` 并加进 batch。**这是跑真实验的前置条件** |
| 域分类器梯度支路（u^grad） | 目前只有 KL 支路（方法文档 §6.3 允许：KL 是 fallback，域分类器是第二支） |
| 通道遮挡校准（v^mask） | 目前只有 Taylor 支路 |
| L_cons / L_pres / L_CORAL | 方法文档 §6.10–6.12，可作后续消融 |
