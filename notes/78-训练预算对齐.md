# 78 - 训练预算对齐（CoRP 官方 / RoboCasa DP / 我们）

日期：2026-10-24

## 1. 官方 CoRP（arXiv 2610.08183）

```text
steps:        80k (LIBERO) / 120k (RoboTwin)
batch:        392
optimizer:    AdamW
lr:           5e-5
precision:    BF16
grad clip:    1.0
EMA decay:    0.999
hardware:     2 x A800
flow:         tau ~ Beta(1.0, 1.5)
task aux:     lambda = 0.01
params:       ~48.9M
LIBERO train: ~8 hours
```

## 2. RoboCasa DP 基线

```text
horizon: 10, n_obs_steps: 2, n_action_steps: 8
batch: 30 (local default) / 192 (official)
DiT: 12 layers / 512 / 8 heads
lr: 1e-4 (DiT) / 1e-5 (DINOv2)
EMA: True
warmup: 1000 steps
```

## 3. 我们之前（200 步 smoke）

```text
steps:        200
batch:        16
lr:           1e-4 (unified)
EMA:          none
n_obs_steps:  1
task aux:     none
-> 约官方的 1/9600 样本量，只能叫 smoke
```

## 4. 新默认（已改）

```text
batch:        30
lr:           5e-5
EMA decay:    0.999
grad clip:    1.0
precision:    BF16
n_obs_steps:  1 (CoRP native)
```

checkpoint 现在同时保存：
- `model`: EMA 权重（用于 eval）
- `raw_model`: 原始权重
- `budget`: batch/steps/lr/ema/grad_clip/precision/n_obs_steps

## 5. 仍然存在的差距（必须写进论文）

```text
1. steps: 当前 200；要 2k-10k
2. task aux loss (lambda=0.01): 已按论文Eq.7实现；官方训练代码仍未发布，
   当前实现是公式复现，task-head隐藏宽度256是显式复现选择
3. n_obs_steps: CoRP 1 帧 vs RoboCasa DP 2 帧
   -> 不能一个 1 帧、一个 2 帧直接比较
4. 硬件: 1 x 4090 vs 2 x A800
```
