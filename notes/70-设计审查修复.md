# 69 - 设计审查后的修复

日期：2026-10-24

## 已修

### 1. [高] action_aware 不再是空转

`CorpRoboCasa.update_action_importance()`：

```text
visual_encoder 输出 z (B,V,T,D)，retain_grad
loss.backward()
score = |z * z.grad| 在 (B,V,D) 上平均 -> (T,)
EMA(momentum=0.9) -> token_style.set_action_importance
```

训练循环在 `loss.backward()` 后调用。测试：
`imp.shape=(256,)`，`sum=1.0`，`nonzero=256`。

### 2. [高] balanced_indices 按 (task, style) 分层

```python
by_task[task][style] = [...]
per_style = max(1, per_task // n_styles)
```

避免 per-task gap 被 style 采样偏差污染；style 多于 per_task 时每 style 至少 1 帧。

### 3. [中] 手工 forward → forward hook

`CorpRoboCasa` 在 `representation_extractor.visual_encoder` 上注册 forward hook：

```text
(B*V,T,D) -> reshape (B,V,T,D) -> token_style -> reshape 回
```

因此复用官方 `RepresentationExtractor.forward`（保留 language batch 检查），
不再复制整段 forward，降低 drift 风险。

### 4. [中] eval 传 domain_ids

已在 `evaluate()` 中传 `domain_ids=b["style_id"]`（上一轮已修，复核确认）。

### 5. [中] DgCD 静默失效加警告

`DgCDScorer.score` 在可用域 < 2 时改为 `warnings.warn(RuntimeWarning)`，
不再静默返回全 0。要在 CoRP 上用 DgCD 必须配 domain-balanced sampler。

### 6. [低] PLACE / DomainDrop 命名

note 66 §4 已列：当前实现不忠实，需补全或改名。
本轮未改代码，保持“待办”，不挂官方名字。

### 7. [低] token_style 只插一次

已明确：我们在 `x_norm_patchtokens` 之后做**一次** patch-token 统计量调制，
不是完整 TFS-ViT（多层 stylization）。论文/note 不得声称“复现 TFS-ViT”。
