## P0：研究合同

### Q1. 我们到底解决什么问题？

**主问题：B（low-level corruption）**

```text
紧凑机器人策略（CoRP）对语义/外观偏移（style/layout/light/background）鲁棒，
但在低层图像退化（Gaussian blur / noise / resolution）下会崩溃。
```

证据：

```text
RoboCasa365 style split      -> 无 gap（median -0.004）
LIBERO-Plus 原生扰动          -> 14/14（小样本）
LIBERO-Plus clean (4 suites)  -> 72.9%
LIBERO-Plus + blur sigma=2    -> 24.5%
LIBERO-Plus + blur sigma=4    -> 0.0%
```

A（style/appearance shift）作为**受控对照**，不是主问题。
C（两者都要）**不做**，避免叙事分散。

### Q2. 我们的 claim 是什么？

**主 claim（待验证）：**

> 在 compact flow-matching robot policy（CoRP）上，
> action-aware token-level statistics modulation 能提升低层图像退化
> （blur/noise）下的动作成功率，且不损害 clean 性能。

**备选 claim（如果方法不成）：**

> 我们系统证明 CoRP 对语义偏移鲁棒、对低层退化脆弱；
> 域敏感通道不是动作因果通道（u≠v），通道级 DG 在机器人操作中失效。

### Q3. 对照是什么？

| 组 | 作用 |
|---|---|
| no-mod | 基线 |
| random_stats | 强制对照（必须有） |
| cross_style_stats | TFS-ViT 式统计量调制 |
| cross_style_stats_action_aware | 我们的方法 |
| blur augmentation fine-tuning | **最强 baseline**，必须先打 |
| （可选）DBCT/SCS-style channel suppression | 通道级 ViT 对照 |

### Q4. Kill criteria（预注册，不可事后改）

```text
K1. 若 clean success < 50% 或模型明显没学会 -> 先修 baseline，不做方法对比
K2. 若 ours <= random_stats（3 seeds 同向） -> 方法负结果，停
K3. 若 3 seeds 方向不一致 -> 加 seeds/样本，不扩方法
K4. 若 blur augmentation 稳定优于 ours -> 以 augmentation 为最强 baseline，
    方法降级为消融/负结果
K5. 若 success rate 与 MSE 结论冲突 -> 以 success rate 为准
```

## P1：冻结评估协议

### 主指标

```text
success rate（primary）
```

### 辅指标

```text
per-dim MSE（eef_position / eef_rotation / gripper / base_motion / control_mode）
per-task MSE
```

### 条件

```text
clean / blur sigma=2 / blur sigma=4
（style shift 作为 secondary，不进主表）
```

### 配对与统计

```text
paired：同一 task、同一 initial state、同一 seed
3–5 seeds，报告 mean ± std
单次结果不下结论
```

### 数据与 split

```text
policy split：train styles 11-30 / val 31-40 / test 41-50
test 只在最终评估跑一次，不参与选择
```

### 允许 / 不允许

```text
允许：LIBERO-Plus + observation-side blur（已跑通，72.9/24.5/0）
允许：RoboCasa-Shift matched-pair（后续受控验证）
不允许：把 train MSE 当验证
不允许：把 hard_train_only=True 的 eval 解释成"gate 生效"
不允许：用 test styles 做模型选择
```

在 P2 通过前：

```text
不在 RoboCasa 上测 success rate

```

## P3：机制审计（与 P2 并行，不需要训练）

```text
1. MCM 式通道 mask：mask 通道后语义是否崩
2. register / outlier neuron：找高范数/style-sensitive neuron
3. neuron path：找 action-relevant path
4. u/v 重叠度：域敏感通道 vs 动作因果通道（IoU / 相关性）
```

产出：一张图，标出哪些通道是 style-sensitive、哪些是 action-relevant、重叠多少。

---

## P4：最小方法（只有 P2/P3 通过后才做）

```text
DINOv2 patch tokens
  -> token-level statistics modulation（action-aware）
  -> resampler
  -> DiT
```

注意：当前实现是**一次** patch-token 调制，不是完整 TFS-ViT（多层 stylization）。
论文不得声称"复现 TFS-ViT"。

## P5：决策树（预注册）

```text
baseline clean success 不达标
  -> 继续训 P2，不做方法对比

ours <= random_stats（3 seeds）
  -> 负结果：u≠v + 通道级 DG 失效

ours > random_stats，但 3 seeds 不一致
  -> 加 seeds/样本

ours > random_stats，3 seeds 一致
  -> 200 步确认 -> 2k -> success rate
```

## 写作资产（不要浪费已有证据）

```text
资产 1（负结果）：u（域敏感）!= v（动作因果）
```
