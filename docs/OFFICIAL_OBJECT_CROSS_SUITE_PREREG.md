# Official LIBERO-Object physical cross-suite table — pre-registration

Date: 2026-11-25. Status: **not run**. This is a cross-suite benchmark
re-test, not a blind/held-out claim.

## Scope

- Suite: official `libero_object`, 10 base tasks.
- Conditions: independent Clean; official physical Lighting; official physical
  Background; official physical Sensor (single-eye benchmark definition) plus a
  bilateral Sensor stress set generated by applying the same official kernel to
  both views.
- Same EGL renderer, FP32, H=E=12, max_steps=220, no Adapter, no gradient.
- Frozen CoRP checkpoint and fixed V1 Block-3 operator.

## Arms

1. `frozen`: contemporaneous EGL baseline.
2. `spatial_ref`: V1 reference fitted only on the 10 Spatial Clean trajectories,
   applied zero-shot to Object.
3. `object_clean_cal`: V1 operator with LOTO Object Clean calibration; reported
   as a separate privileged calibration arm, not as zero-shot.

## Required outputs

- Clean, Lighting, Background (table/scene split if available), Sensor single,
  Sensor bilateral, standard100, combined130.
- Rescue/harm/net vs Frozen and vs spatial_ref, paired by (task, instance,
  seed), task-cluster 95% interval.
- Clean rescue/harm; no claim without zero new Clean harm.

## Promotion rule

`spatial_ref` may be called a zero-shot cross-suite transfer result only if it
beats Frozen on the standard Object set and does not lose Clean. `object_clean_cal`
may be reported only as a calibration upper bound. No Blind, no Object synthetic
rows, no cherry-picked seed.
