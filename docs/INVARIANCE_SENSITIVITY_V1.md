# 双视角外观不变性与物理位置敏感性：单层算子 V1

已用 EGL 采集 100 个 Dev t=0 实例、37 帧额外的几何反事实（含0位移）。单层顺序为 DINOv2 的第3/6/9/12个 residual block 输出，均在最终 LayerNorm 前；保持 CLS，两个相机使用同一公式和强度，不依赖另一只清晰相机。模型冻结、无梯度、未执行候选动作、未访问 Blind。

四个层的恒等旁路校验 548 次；原生单噪声官方输出与手动批量采样的最大逐坐标差 2.15e-06。LOTO 严格排除本任务 Clean；逐通道阈值由内层8任务拟合、在第9个源任务上打分再取分位数。不是按目标动作误差择优。

## 预设判决

24 个非恒等配置中，通过名义开发关口：['3_uniform_0.5', '3_dead_0.5', '3_dead_0.75', '6_dead_0.5', '6_dead_0.75']；对 24 配置 × 3 域 × 2 个分量做多重比较敏感性检查后：['3_uniform_0.5', '3_dead_0.5']。

B 有 108 个同任务位置配对，其中 97 个通过 Frozen XYZ 响应下限，来自 5 个任务。它们共享位置与噪声，不能按独立轨迹计数。Frozen 位移命令差与目标物理平移的平均方向余弦（逐对中位数）为 -0.377；几何指标评价的是保留 Frozen 响应，不是专家合理性证明。

建议固定第 3 层、95% 死区、α=0.50 做下一轮 Dev 闭环对照。两种第 3 层 α=0.50 配置在多重比较检查中通过 A1 和 A3；A2 的旋转下界未超过零。死区版与均匀版的外观收益接近，但 Clean 平均 XYZ 漂移从 0.01596 降到 0.00847。死区版双眼 Sensor、背景、灯光分别仍有 10/30、8/30、4/30 的 XYZ 参考距离变远。只有 10 个任务，校正后下尾只涉及约 5 个 bootstrap 抽样，不能作确认性总体保证。

首段平均 XYZ 命令差与物体位移同向的只有 38/97 对；运动坐标和动作时序也会影响此检查。没有专家动作或实际执行，不能据此判定抓取正确性。

## 如何解释

A 的扰动相机是评测器设置，不提供给算子。A1 含29条双眼模糊和1条双眼雾；A2/A3 是物理一致的官方场景渲染，不是往两眼粘同一块纹理。B 在有相同 tabletop 语义的任务内实际移动目标自由关节，不用不同语言/任务构造假几何配对。运动后执行 forward 刷新，不执行物理控制动作。排除新增/改变目标接触伙伴、或额外穿透>1mm的变体；不保证所有姿态都能闭环成功。

判断只适用于当前参考统计、阈值、层位、强度和首帧；若无合格候选则停止这组算子，不叠多层/WCT/EMA，也不推出所有浅层修正都不可能。若通过，仅获得下一轮同期 EGL 多种子闭环资格；没有任何闭环收益、安全性或 Clean 保持性主张。
