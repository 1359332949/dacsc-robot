# Experimental contract: before outcome inspection

Use only the frozen 100 Dev IDs. Three policy seeds; standard EGL benchmark does not change between arms. New independent physical rollout per method per case, including rejections. Within each case rerun contemporaneous Frozen and the original continuous agent-only method. Fixed method copies its exact gate receipt and uses 0.10 at acceptance, never retests fixed .10 or selects by outcome. A rejection uses the native sampler; require same two initial pixels, physical state and exact executed-action digest/steps/outcome as Frozen. Same matched-state render-rounding contract as 5795eb8. Store the continuous gate agreement with the previous run separately; use fresh paired outcomes in the main analysis. No RGB alignment or Clean statistics.

Symmetric method: two post-LN prefix Value coefficients, ordered by actual view names; 48 tokens per camera. Preserve Keys, wrist/agent relative token order, nonvisual Values and weights. Ten joint projected Adam steps at .3, same 4 fit / 4 acceptance seeds as original; regularizer .001*sum(s²). Nearest point to unconstrained update on union {s0=0,s1∈[-log(100),0]} or {s1=0,s0∈[-log(100),0]}. At an exactly equidistant tie keep identity (symmetric tie policy, not nearest if both candidates nonzero). No camera/factor/outcome information enters the gate. Identity on rejection (validation relative energy ratio >.80). One gate per episode at t=0.

Seed-0 wrist stress: same 30 Sensor cases, swap ONLY the destination pixels of the original sensor kernel before policy preparation. Preserve code, severity, step/noise seed and wrist orientation; assert untreated camera is bit-identical. Keep identity/copy-on-write checks independent of curve checks. Run fresh wrist-corrupted Frozen + symmetric. No mixing with official benchmark or historical agent-corruption outcomes. Stress includes fog as well as blurs.

Exploratory promotion: standard Sensor mean gain >=20 percentage points, positive net at each seed, fewer than or equal to 1 non-Sensor trigger per seed, no non-Sensor harm. For wrist stress require positive net vs wrist-corrupted Frozen and a strict majority of accepted episodes downweight wrist; wrong-eye actions and harms must be shown. These are engineering screens, not statistical tests of universality. Fixed-vs-continuous: report both directions of direct paired discordance, also conditional on the shared accepted subset; lack of significance is not proof of equivalence. Seeds repeat the same cases; report unique cases, task-cluster uncertainty descriptively. Never unlock Blind as part of this campaign.
