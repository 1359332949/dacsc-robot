# F-SFC V1：全 100 条首帧诊断（2026-11-24）

**STOP：不进入 EGL 三种子闭环。** 这是对历史 OSMesa 像素缓存的真实 CoRP 首帧前向和反传，不是 EGL rollout。每个任务的通道先验只看另九个任务的 Clean；每个方法用相同的四个优化噪声、四个验收噪声和四个不同的评价噪声。主方法为软死区 Jacobian，其他方法是消融。没有运行 Blind 或使用配对 Clean 动作选门控。

两类尺度分别为 patch 总体标准差（用于扰动权重）和跨场景 patch 均值标准差（方差向全通道平均方差收缩10%，用于均值死区）；硬掩码消融也使用修正后的尺度。软版仅屏蔽零权重通道。10 项单元测试通过，另用原始结果逐条验证源列表、随机数隔离、验收、回滚后动作及样本与 Clean 的配对。

EGL：两份旧 runner 使用 resolved BDDL；服务器构造 30 个 Sensor 环境实测 native noise 30/30 为零，手工噪声码 30/30 非零。修复后在 reset 前强制置零，并去除 Frozen 首帧重复计算。旧实现没有把前一次手工变换作为下一次输入。此次没有重跑/改写 EGL 成功率。详情见 EGL_REBASELINE_RESULTS.md。

## 判读

软版三臂各接受100/100次，包括10条 Clean。曲率＋源域偏离代理损失通过验收，不等于动作不漂移，更不等于自主识别传感器风险。源域 Jacobian 加权没有形成跨三域一致优势。放开硬掩码虽允许零均值漂移的通道被 Flow 梯度移动，但在这个控制实验里，Sensor 失败组反而是硬掩码的参考对齐更好；它仍然伤害 Lighting 的参考对齐，不能事后改为主方法。

小分母敏感性：若改用“所有样本距离之和的降幅”，主方法 Sensor/Background 失败组 XYZ 分别为 +6.75%/+1.08%，与逐例平均的 −6.35%/−26.1% 不同，不能说每条失败轨迹都恶化。Lighting 失败组两种算法都明显恶化（均值绝对距离约 0.374→0.629，总距离降幅 −68.0%）。三个原成功 Shift 分组的平均绝对 XYZ 距离全都增加；这与10条 Clean 的漂移是停止的直接依据。不把漂移翻译成误伤数或成功率，本轮没有执行修改后的动作。
