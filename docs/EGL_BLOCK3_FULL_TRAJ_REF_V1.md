# 第三层全轨迹参考：EGL 配对闭环与桌面时间窗

10 条 seed 0 Frozen Clean 提供 101 个实际推理块，外层 9 任务、内层 8+1，按块等权。全局三臂和额外桌面两臂共 1,260 局，另有 10 局源采集。全部为 Dev。

## 两个问题分别看

全轨迹参考在标准 Dev 成功 233/300，旧参考 231/300，同期 Frozen 217/300。在双眼 Sensor、桌面纹理、场景纹理与灯光上，相比 Frozen 的净局数分别为 +10、-1、+1、+6。标准集与双眼压力集重复使用 Sensor 身份。

桌面对 Frozen 的救回/误伤从旧参考的 2/7 变成全轨迹参考的 5/6；Clean 成功 29/30（对 Frozen 救回 0、误伤 0）。减少激活与避免动作误伤是两道不同的评价关口。

历史七局中，本轮复现原损伤 7/7；其中仅早期开启就失败、仅晚期开启就失败、两种单独时间窗都失败、两种都成功（只有全程失败）的局数依次为 3、2、1、1。新参考实际成功 2/7。以下时间窗使用旧参考，仅用于归因；不能凭一个时间窗的胜负推出帧内哪个通道导致失败。

- standard100：全轨迹参考相对 Frozen 各种子净数（0/1/2）：+10, -1, +7。
- dual_sensor：全轨迹参考相对 Frozen 各种子净数（0/1/2）：+2, +3, +5。
- lighting：全轨迹参考相对 Frozen 各种子净数（0/1/2）：+4, -1, +3。
- table_texture：全轨迹参考相对 Frozen 各种子净数（0/1/2）：+3, -2, -2。

来源核验：10 次 Clean 源重放均与历史胜负一致，完整动作哈希匹配 9/10；其中一局为 103 而非 105 步，两者均有 9 个实际推理块。闭环 390 组中，Frozen 与旧参考的成败和上轮分别匹配 389/390、390/390；本报告只使用本轮成对结果。
