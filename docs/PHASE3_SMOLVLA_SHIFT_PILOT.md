## 执行与不确定性补充

- 首次运行 + 续跑的主实验计时约 65.1 分钟，不含前置实现与物理预检。官方 Glass Python 循环曾使一局达到约 901 秒；经 40 项真实/随机图像、多强度校验，改用像素输出及 MT19937 最终状态均逐位一致的整数循环加速（独立 CPU 测试中位约 113.6×）。随后满 220 步 Glass 一局约 156 秒。此加速只涉及评测扰动生成，不是 TTA 方法提速。
- 保留首次完成的全部 53 臂文件，最终 SHA256 逐一一致；中断的未完成回合不计分，续跑同一条件/种子。仅调度改变为领取队列，优先处理昂贵 Glass；不按成功/失败筛选或重跑。原模型、干预公式、参考、强度、条件名单、随机数与像素分布不变。
- Motion/Gaussian/Zoom/Glass 均为两臂 0/4，存在严重地板效应；不能把零差异说成鲁棒或等价。所有配对差为零时 bootstrap 区间会退化为 [0,0]，不代表总体风险为零。
- McNemar 为用户要求的名义精确检验，不调整同任务相关性及多重比较；同时给出按任务整组重采样的区间，只有十个任务簇。
