# P-SAFE 设计审查：保留假设，驳回整包立项

2026-11-24。本次是文献和设计审查，无 P-SAFE 代码或新实验。此前已启动的 EGL 视角消融已另行归档，不能替代本方案证据。

**要证明的不是把目标图变得像平均源图，而是在两只相机都可能受损时，削弱外观变化对动作的影响，同时保留真实空间变化对动作的影响。** 只满足前半句的常数策略就能“完美不变”，却不能抓取。可保留共享规则、部分有界仿射、严格恒等与无更新选项；暂缓四层、敏感度比值、Flow选档和跨局EMA的组合，不承诺统一收益或原创性。

## 核查的原始文献与边界

- [PEA, ICLR 2026](https://proceedings.iclr.cc/paper_files/paper/2026/file/cea5bc68b890bffb10f18aaaab2becb1-Paper-Conference.pdf)：Eq.1 是层均值之差和方差之差的范数和；分两次前向估权、应用 WCT。Table 6 ViT-Base ImageNet-C：不适配55.5、仅协方差对齐25.2、加权52.9、加权加EMA 64.5。说明多层强对齐会伤害，也说明 EMA 在该设置有价值；不是单条操控轨迹上的保证。没有用最后一层与四层的分类数字为 CoRP 选层。
- [FOA, ICML 2024](https://proceedings.mlr.press/v235/niu24a.html)：Eq.5 使用熵与跨层 CLS 均值和标准差差异，前向演化搜索 prompt；不是冻结动作头的高斯标准化 W2 定理。
- [QuAR, arXiv:2610.08358](https://arxiv.org/html/2610.08358v1)：在量化器输入上部分重标定，Fig.1 的 Wasserstein-1 描述量化码直方图；不能当作 FP32 CoRP 上标准化 W2 或动作几何保持的直接依据。
- [THE COLOSSEUM, RSS 2024](https://arxiv.org/abs/2402.08191)：更相关的借鉴是操控闭环、分因素与组合扰动评估。分类 TTA 文献提供候选变换，操控证据决定其是否值得采用。

## 数学审查

1. 一维高斯 W2² 的分子是均值差平方加标准差差平方；非高斯或多峰 patch 仅凭两矩不能得真实 W2。除以仅由源决定的方差后不是交换两分布仍对称的距离；平方距离也非一般度量。目标方差为零不能保证源方差稳定；即便加 epsilon，均值项仍可任意大。KL 不对称本身不构成不可用的理由。不要把别的任务间正常场景差异当作当前任务的外观损坏。均值的校准使用场景均值的跨场景尺度，尺度变化单独校准；九个任务的 patch 不能当作独立的九乘256张图。建议先报告未标定/覆盖不足，而非宣称95%安全。
2. 附件的 alpha=0 时，gamma=sigma_t/sqrt(sigma_t²+eps)，并非恒等。明确旁路，或先求有界尺度比 b，再用 `x + a*((mu_s-mu_t)+(b-1)*(x-mu_t))`；a=0 逐位返回 x。b 正且有界只保持本层本通道 patch 次序/相对差的比例，不保持通道方向、attention 排序、遮挡或 3D 几何。目标对比度为零时，仿射不能找回已消失的物体边界。源均值和方差对齐不等于回到源流形。
3. 反例：交换目标与干扰物的 patch 位置可使各通道前两矩不变，但所需动作改变；反过来，同一个房间中物体大小/距离改变，会使前两矩变动，却不应该被纠正。这是统计量的不可辨识性假设测试，不声称整网在真实图像下严格置换不变。双眼都丢失证据时，合理动作是原样保留或在独立任务中研究主动获取信息，不承诺从无证据中恢复。
4. 标量搜索不等于小扰动：2视角×4层×384通道=3072个数据依赖系数，虽然不是3072个自由训练参数。每层缩放有界也不限制复合网络的动作漂移。逐层注入可能改变深层观测统计；须声明比较/拟合的是原始还是已适配前缀，不重复拉回同一偏移。IQR 可能为零；Jacobian 小可能是局部饱和、单位选择或动作阶段，不能据此识别几何无关通道。若用 Jacobian，只能称部署期无反传，不能称全流程零反传。
5. C_rel 是离散速度非常量性，不是熵或置信度。错误恒速动作也可令它为零。此前同类 EGL 压力测试有21条 Frozen 失败，却没有一次成功转好。独立 z0 防的是采样噪声过拟合，不证明代理与任务一致。删除“W2 降且曲率不坏即可接受”的 OR 自证规则：候选本来就是为降低 W2 构造。四档强度×四噪声×十步至少160个样本级速度计算，另有独立验收；可 batch/缓存，不等于四次 DiT 或保证几十毫秒。
6. 95%逐通道分位数不能推出整帧 No-Op；多通道、多层、多次重规划选优均改变误报概率。若做源侧阈值，外层排除任务 T，内层按其余任务留出估整帧最大变化/动作漂移，按任务报告并保留样本少的限制。两相机共享算法、超参、候选和否决规则；相机光学与取景不同，可有各自的源标尺，但交换输入和标尺只应交换两路处理。Episodic 与 CTTA 是不同信息预算；先固定单局重置，禁止跨局流状态。每个候选用同一份当前/历史统计快照，EMA 只对真实观测更新一次，不随候选推进。

## 最小可证伪路线（建议，不是开跑指令）

第一阶段是资格检查，不以离线收益代替闭环。用其他任务的 Clean，构建两种源内配对：固定物理场景/动作阶段，双眼均受外观干预；固定外观，作已知任务相关几何变化（优先同任务不同物体姿态，固定语言，避免挪动无关干扰物）。第二类应保留对应真实动作/观测差异，第一类希望更稳定。匹配本体状态、语言和流噪声，标签/真值只在离线评价使用。用可观测的双视角投影、对应 patch 邻域与局部动作响应作破坏探针；不能把空间索引不变当作几何验证。对两眼共同受损、信息已不可恢复的场景允许不改。在此阶段不尝试新目标数据、不根据目标标签选层。

通过后只选一个预定浅/中层、一个有界对角候选、一个共享强度、严格身份旁路。先无 Jacobian、无跨局 EMA、无 WCT；Gate首版仅作明确否决，动作漂移约束也只能是预算，不能当安全保证。后来若引入 Flow 选档，比较相同候选的固定强度、Flow 选择和 Frozen，测试选择器增量。多层、敏感先验等一次只加一个有可证伪预言的因素。双眼受扰的主场景预先覆盖不同相机间共享/独立外观变化及合理复合扰动；不能用同一张二维噪声贴图伪造双眼三维一致背景。标准 Sensor 和单眼反测留作辅助。完整同期 EGL Frozen，多种子平衡配对，报告 Clean、原成功、恢复/损失、每条件最差退化、门控误放及每次查询延时。统计/方法、相机相关性、扰动强度和选择规则先锁定；已有 Dev 不包装成确认性测试。仅在比较证明净增且无不可接受退化时讨论下一阶段。

## 判决

六条纪律：方向上符合双视角与单机制；双眼共损尚未被验证，几何保持未被证明，若干公式/论文归因需修正，闭环与独立校准尚未通过。因此本轮**驳回直接实施完整版与解锁盲测，保留受限算子的研究假设**。最有区分力的问题是“在保留对任务几何的响应时，能否减少对双眼共同外观变化的响应”，而不是哪一层对齐后距离最小。
