# F-SFC V1：实现审查，尚无模型实验

本次交付只做静态检查与合成张量单元测试。probe 默认打印规格，不加载模型；显式 `--execute` 才可能推理。未访问服务器、未运行 CoRP/模拟器，未采数据，未跑 42 例，也未改变任何过去的实验结论。实际调用路径、CUDA 梯度、准确性和耗时均未经实机验收。

## 一条样本如何处理

1. 使用 `abb28db` 的已校验 t=0 特征缓存，锁定冻结 Dev manifest、checkpoint SHA、逐例 NPZ 与 baseline 回执；实际执行时，重算原图 DINO 出口、4 个 z0 的 hash 及恒等动作。缓存已含官方旋转/缩放后的双视角 RGB，不二次翻转。无闭环或 Blind 接口。
2. 对任务 T，只取另外 9 个不同任务的 `dev_clean`。先按任务/角色过滤，再拟合任何先验。每张图的漂移和导数可跨折缓存；所有均值、方差、比值及归一化每折重新计算。这里是其他任务 **Dev Clean 参考**，不是 checkpoint 的原始训练集或独立安全校准集。
3. 两个相机分别统计七族合成变化（亮度、对比度、色温、伽马、高频纹理、Gaussian、水平运动模糊）；每族一个固定变换，等权。尺度是按 source 场景及 patch 池化的总体标准差，非图像均值的跨场景标准差；用来给图像平均值打分可能让局部漂移被平均掉。这是预先声明的限制。七种变换不会保证覆盖实际光照或纹理。
4. 重要性使用**未裁切**的 12×7 controller 输出，对单个输出坐标分别求 VJP，沿 patch 和输出坐标平方求和，再开根；最后对 4 个 z0 和场景取平均。不是对 84 维输出求和再反传。84×4=336 次反向/源图；按10个唯一源图缓存，完整参考遍历为3360次，不预估10分钟。是冻结策略局部导数，不是专家任务价值；平移/旋转/夹爪的单位混合会影响排序。后续若改变坐标尺度，需另列消融。
5. 三臂分别用动作 Jacobian、图间同位置 std（再对 patch 平均）、恒为 1 的权重。仅变分母/权重，保持两视角、七族、正则、噪声和优化一致。`base_std` 是公平的旧分母消融，**不是重跑旧版完整方法**。旧 `v2_channel_sensitivity.py` 的 `motion` 实为3×3均值核；后来 `v2_channel_sensitivity_sourcefit.py` 已含真正的水平运动模糊和纹理扰动。先前得分不能单独归因于旧分母。
6. 元素门控是有界凸组合；凸组合不能保证留在真实特征流形，也不能保证保持动作。附文写的 dead-zone loss 本身不足以强制正常通道不变。因此额外采用**基于未编辑本帧的显式活动掩码**：在死区内或源先验为零的通道无论曲率梯度如何都不可编辑。过死区并不代表通道坏了。有些危险通道只有弱梯度或只有局部 patch 损坏，仍可能漏检。
7. 实现采用 tau=2，lambda=1，eta=.01，delta=.001，Adam lr=.1，10步；未在 Dev 上调参。主目标及正则均按两视角全部通道平均。g=0 精确恒等。4个 fit / 4个 acceptance 噪声源自独立命名空间，三臂相同；评价复用与 Clean 参考配对的另4个历史噪声。两个验收条件同时满足才应用：L1 <= .95 L0 且 C1 <= 1.05 C0；非有限、损失无改善或曲率不合格均拒绝。Noise held-out 是更新验收，不是独立任务测试。源均值项自己下降不说明动作变好。
8. `EpisodeGate` 是可选状态机：每集新建；每2个chunk复查，保留门控已不优于当前恒等目标时，用3步热启动，失败回零。调用者应按 episode、chunk 和 stream 派生新噪声，防止多次复用验收样本。42-case runner 仅用 t=0，不连入闭环。

## 未来 probe 的解释边界

附件未逐条列出 42 个 ID。代码明确采用冻结名单中的 32 条历史 Shift 失败 + 10 条 Clean，非随机抽样；历史标签仅用于选诊断队列。先验子程序无标签参数，优化子程序也无同任务 Clean 输入。各臂结束后才以配对 Clean 动作作离线参照。每例记录源任务名单、各臂先验、门控、验收指标、四噪声动作及裁切后 xyz/rotation-coordinate/all 参考 L2。离线距离不是专家动作，不是任务成功。**这42例既不能估计成功 Shift 的误伤，也不能验证 Lighting −4 或 Clean −1 已消除。** 将来先验证真实缓存重放、冻结权重/恒等门控数值及耗时，再讨论是否补成功 Shift 及闭环；这次没有启动这些步骤。

## 对原始论文的核对

- [Efficient Test-time Adaptive Object Detection via Sensitivity-Guided Pruning](https://arxiv.org/abs/2506.02462)：对象检测 CTTA，图像/实例层面的域敏感度、加权稀疏剪枝及随机再激活。支持要区分域敏感通道的研究动机，不提供本项目的动作雅可比公式。
- [RECLAIM](https://arxiv.org/abs/2611.24494)：利用冻结 VLA 对局部视觉干预的**注意力响应**与机器人几何选择和复核局部净化方式，研究对抗 patch。不能把它引用为对动作雅可比通道保护的直接验证。
- [GD-Adapt，ACL Findings](https://aclanthology.org/2026.findings-acl.350/)：对象是多模态情感分析，方法包含预训练生成正则、流形感知扩散及贝叶斯蒸馏。其对过度自信的关注可以借鉴；不能说它验证了这里的双阈值、零训练机器人方案或首创性。
