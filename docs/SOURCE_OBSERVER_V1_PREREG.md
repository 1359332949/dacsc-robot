# SOURCE_OBSERVER_V1：首次评分前冻结的方案

本方案在本轮首次模型拟合和 Validation 评分前提交；源数据结构、episode 长度和成败分布已知，不宣称对这些元信息盲法。配置唯一来源为 `experiments/source_observer_v1.json`。本轮仅关口 A，不读取受控 Lighting 或 target-test，不新增 seed 或 rollout。

## 表示与模型

每视角将 48×768 tokens 沿 token 轴平均为 768 维；Source Fit 的完整 chunk 所涉及的去重边界上做状态等权 PCA，固定 8 维。PCA 不使用 Validation，也不根据保留方差调整 rank。报告方差与 delta 能量覆盖率以说明压缩损失。

动作是实际执行的 12×7 clipped commands，分为连续三段、每段四步求均值，得到 21 维；因此不会保留段内全部动作细节。state8 是原数据的当前本体状态。

- M0：state8 + action21，29 维输入。
- M1：PCA8 + state8 + action21，37 维输入。
- M2：PCA8，8 维输入。

目标为同一 PCA 坐标中的下一边界变化；使用 Fit 的逐维 delta 标准差缩放，尺度下限为 `max(1e-6, 0.1×各维标准差中位数)`。输入标准化只用 Fit。正则强度 alpha=1，截距不惩罚；优化目标按状态和该状态内完整 chunk 等权，所有样本权重之和为 1。不存在调参或 Validation 重拟合。

训练使用全部 10 个 Fit 状态，包括两个最终未成功状态；主分析只用 101 / 74 个完整 chunk。部分 chunk 的目标末端不进入 PCA 或训练；与完整 chunk 共享的边界仍是合法观测。

## 实现隔离

`fit` 子命令只打开 source_fit 轨迹，写入模型 NPZ、配置/代码/训练输入哈希和 Fit 统计；`evaluate` 在另一个进程读取已冻结模型后才打开 source_validation。评分前后模型 hash 必须一致。

训练代码和数据 API 不接收剩余步数、轨迹总长、episode 成败、state id 等作为模型输入；这些字段仅用于权重、分组和诊断。

## 主评价与继续判据

主误差：每状态的对角缩放 PCA delta RMSE。报告两视角、M0/M1/M2 各自 10 状态的全部值、状态中位数/均值/分布；同时报告原 768 维 pooled-feature 重建 RMSE，避免仅靠低维投影宣称解释完整视觉变化。

逐状态增益 `g_s=1-RMSE(M1,s)/RMSE(reference,s)`。置信区间以初始状态为抽样单位（10000 次固定 seed bootstrap），不重采样 chunk。区间只作小样本探索性描述，不给总体统计安全保证。

每视角必须全部满足：

1. M1 对 M0、M2：中位相对增益至少 5%，至少 8/10 状态误差更低，状态 bootstrap 的平均增益 95% CI 下界 >0。
2. M1 对两个非学习对照（零变化、Fit 平均下一状态减当前状态）的中位增益 >0。
3. 在共同早期范围 `chunk_end<=72` 以及排除临近终点 `remaining_after_chunk>24` 两个预定诊断子集，M1 对 M0/M2 的状态中位增益均 >0。

两个视角都通过才记 Gate A PASS。任何一项不通过记 STOP_V1，不调参补救，不自动挑选好看的视角转入 B/C。这是预先选定的工程决策标准，不是论文定理；失败不否定所有正常观测模型。

## 共享输入和时间构成检查

- 两个非学习对照分别预测 delta=0，以及 `Fit下一状态均值-current`，直接检查共享当前 z 导致的回归均值收益；它们不是新增风险模型。
- 固定 M1 的动作块在每个 Validation 状态内部循环移位一块，保持当前视觉/state8 不变。该描述性测试仅检查模型对动作条件的敏感性；错配动作可能超出支持范围，不能证明动作因果作用。
- M1 vs M2 差别含本体状态和动作两部分，不能将全部增益归给动作。
- 分别报告 end<=24、24<end<=72、end>72 的误差；这些是时间段，不冒充有物理标签的任务阶段。
- 按离终点剩余步数分组，报告每状态误差与 elapsed/remaining 的相关性，目标变化幅度与误差关联、去除末尾24步后的结果。
- Fit 的成功/未成功轨迹误差仅作训练分布描述；Validation 全部成功，无法检验 Validation 上按成败的风险区分。
- 方向误差只在真实缩放变化范数>0.1 且预测范数>1e-12 时报告，并给有效比例。

阶段分组只能暴露明显混杂，不能“直接排除”所有靠任务阶段预测的替代解释。真正在语义任务阶段内控制风险仍需要事件标签。

## 查阅的原始依据

- scikit-learn Common pitfalls / Ridge 官方文档：预处理和拟合仅训练集；明确 weighted ridge 的尺度与正则目标。
- PhyLatent（arXiv 2608.05720）的问题分解：视觉表征可预测性、物理不变性、不同动作未来的区分不能互相替代。
- Selective Classification Under Distribution Shifts（arXiv 2405.05160v2）：分布偏移检测不能替代对错误的识别。本轮只做正常预测，未进入选择性风险预测。

这些来源不为本轮任意选择的 rank=8、alpha=1 或工程门槛背书；这些是本次预先冻结的有限容量设定。
