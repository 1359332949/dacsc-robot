## 1. 科学假设（可证伪）

> **在 CoRP 的动作生成接口上，面对语义保持的视觉变化，策略应当保持相同的有效控制决策；
> 利用多视图动作共识作为无标签目标进行测试时适配，可以在不破坏动作敏感（A）行为的前提下，
> 提高视觉扰动下的成功率。**

可证伪预测：
1. 多视图共识动作比单视图动作更接近"视觉不变的正确行为"（离线可测，无需 rollout）；
2. 以共识为目标的自监督适配在视觉扰动下优于 Frozen；
3. 硬 A-零空间约束不劣于软 penalty，且比无约束更新更稳定；
4. 在 clean（无扰动）上不造成显著退化。

## 2. 方法定义（SG-CPA）

### 2.1 反事实视图与动作共识

给定观测 `o_t`、状态 `s_t`、指令 `g`，构造 K 个**语义保持**视觉视图：

```
õ_t^(k) = T_k(o_t),   k = 1..K
```

用**冻结的当前策略**（β=0）对每个视图采样动作块，**共享同一个初始噪声 ξ**：

```
A_0^(k) = Sample(π_{θ,0}(õ_t^(k), s_t, g); ξ)
```

共识伪目标：

```
Ā_t^0 = (1/K) Σ_k Γ_k^{-1} A_0^(k)
```

- LIBERO 为单臂、动作在机器人基座坐标系；光度量变换不改变动作坐标系 → **Γ_k = I**；
- 若将来引入相机位姿变化，必须使用几何一致的投影/坐标映射，**不能**用图像的任意仿射变换近似；
- 动作在**归一化空间**（与 CoRP flow 输出一致）计算共识。

### 2.2 反事实流一致性损失（CoRP 原生 Flow）

```
X_τ = (1-τ)·ε + τ·Ā_t^0        (CoRP-native: τ=0 噪声 → τ=1 数据)
v*  = Ā_t^0 − ε
L_CFC = E_{ε,τ} (1/K) Σ_k || M ⊙ ( v_{θ,β}(X_τ, τ, õ_t^(k), s_t, g) − v* ) ||²
```

- 与 SALT 的区别：目标来自**当前观测的多视图共识**，不是历史动作 leftover；
- K=1 且不加扰动时，目标即当前策略自身输出 → 初始梯度≈0（天然 no-op sanity check）。

### 2.3 A-零空间更新（核心创新）

接口写回 `z ∈ R^768`（最后 Euler 步、token 均值，与 A 同一坐标系）；适配参数 `β ∈ R^d`
（沿用 K-projection 的 SVD 缩放，d=768）。

动作敏感 Jacobian：

```
J_A = A^T (∂z/∂β)   ∈ R^{r×d},    r = 5
```

投影矩阵：

```
P_null = I − J_A^T (J_A J_A^T)^† J_A
Δβ* = −η P_null g,     g = ∇_β L_CFC
```

实现含义：
- 用 `r` 次 VJP（`autograd.grad`）得到 `J_A` 的 r 行（r=5，成本可控）；
- 一阶意义下 `J_A Δβ* = 0`，即更新不改变 A 方向的接口写回；
- 由于采样过程非线性，做**有限步校验**：更新后重新测 `‖A^T Δz‖`，超阈值则缩小步长/回退。

### 2.4 与 SG-SALT 的关系

| | SG-SALT（已完成，作为历史对照） | SG-CPA（新方向） |
|---|---|---|
| 自监督信号 | 历史 leftover（SALT） | 当前观测多视图共识 |
| A 保护方式 | 软 penalty λ‖AᵀΔz‖² | **硬零空间投影**（一阶） |
| 对 SALT 的依赖 | 核心 | 无（SALT 仅作 baseline） |
| 需要调的关键超参 | λ | 视图集 K / 步长 η / 投影秩 |

## 3. 关键假设与风险（必须先验证）

| # | 假设/风险 | 为什么可能失败 | 验证方式（离线，不跑 rollout） |
|---|---|---|---|
| 1 | **多视图共识可靠** | K 个预测可能分歧很大，平均后是"平均动作"而非正确动作 | 在 clean/扰动数据上测：单视图 vs 共识的动作一致性、与真实执行动作/成功率关系；若共识不优于单视图 → 方法前提不成立 |
| 2 | 视图变换语义保持 | 背景替换/相机变化可能改变动作语义 | 先只用**光度类**（噪声、模糊、亮度/对比度/色调），背景/相机放第二组；对每个变换测 clean 上动作变化 |
| 3 | A 零空间过强 | 共识目标本身需要改变 A 方向；硬投影可能阻止必要适配 | 对比 hard projection vs soft penalty vs 无约束；并记录 `‖A^T Δz‖` 与成功率 |
| 4 | J_A 计算成本 | 每次更新 5 次 VJP + 2 次采样，可能 >2× SALT | 记录单步耗时；必要时用有限差分或降频（每 n 步投影一次） |
| 5 | 视图数 K 的方差 | K 太小共识噪声大；K 太大成本高 | K ∈ {2,4,8} 离线比较共识方差 |

## 4. 适用的视觉变换（分级）

| 级别 | 变换 | 动作语义 | 首版是否使用 |
|---|---|---|---|
| A（安全） | 高斯噪声、高斯模糊、亮度/对比度/饱和度/色温抖动 | 不变 | ✅ 首版 |
| B（中等） | 背景纹理替换（不遮挡物体）、轻度光照方向变化 | 通常不变 | 第二版 |
| C（高风险） | 相机位姿/视角变化 | 需要几何映射，且 A 子空间正是在该类扰动下定义 | **首版不用**，单独研究 |

理由：Camera 扰动是静态的、且与我们保护子空间 A 的来源耦合；首版用光度类变换可以**独立检验"多视图共识"这一核心假设**，
避免把几何/坐标问题带入。

## 5. 进入实现前的验证门（不写代码也要能做的检查）

1. **共识保真度（最重要）**：在 clean 与光度扰动观测上，比较 K 视图共识动作与单视图动作的差异、
   以及共识动作与策略在原始观测下动作的差异；若共识与单视图差异巨大且无一致方向 → 停止；
2. **K=1 no-op**：K=1 且目标为当前观测时，损失≈0、β 更新≈0（单元级验证）；
3. **投影正确性**：合成 Jacobian 下 `J_A P_null ≈ 0`；有限步后 `A^T Δz` 受控；
4. **变换合法性**：每个候选变换在 clean 上使动作变化在可接受范围（记录分布）。

## 8. 与相关工作的边界（论文层面必须写清）

| 方法 | 已有贡献 | 我们的区别/风险 |
|---|---|---|
| SALT | leftover 自监督 + flow matching TTA | 我们不用 leftover；SALT 作为 baseline |
| MEMO | 增强视图的边际一致性（分类） | 我们把一致性变成**连续动作块共识 + flow 蒸馏** |
| PDF | 视觉增强/动作投票/扰动头 | 我们做参数高效适配 + A 零空间约束，不做延迟反馈头 |
| VANE | 未来视觉表征预测 + 验证更新 | 我们不预测未来表征；若走 FPA 路线需重点界定 |
| OGD | 重要方向梯度正交投影 | 我们用**动作敏感 Jacobian** 定义保护子空间（VLA 接口） |

> 结论：多视图一致性与梯度投影本身都不是新理论；论文创新必须落在
> **CoRP 连续动作更新的共识蒸馏形式 + 由动作敏感 Jacobian 定义的零空间约束 + 实验证据** 三者结合上。
